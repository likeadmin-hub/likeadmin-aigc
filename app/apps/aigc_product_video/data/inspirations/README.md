# 平台内置商品视频模板

租户后台“设为内置模板”生成经过校验的 JSON 配置。该目录随源码更新分发；接收端自动同步为平台模板，所有已开通商品视频的租户共享使用，不覆盖租户自建模板。

这里只保存创作配置、稳定的算力市场模型标识和已明确公开的 OSS/COS/七牛素材路径。不保存存储密钥、临时签名、商品来源链接、用户身份或报价，不下载/上传/复制图片视频。新增或修改的 JSON 应随下一次源码更新一起提交；这不是发布包。

关闭或删除内置模板会保存停用/删除标记供更新同步，不删除共享文件，以保护已经创建的草稿。不要直接移除已分发定义文件。原素材必须保持公开可读；更改原 OSS 对象 ACL 会影响共享预览。

## 后台使用与更新

租户后台「商品视频 → 灵感模板」将本站模板“设为内置”，创作记录也可直接“设为内置模板”。发布后生成独立平台模板；租户原模板不改变。平台可以编辑、下架或删除内置模板，租户后台只能查看。相同平台上的启用租户立即共享；独立部署需同时更新源代码、数据库迁移和此目录下已发布的 JSON 定义，首次读取会幂等同步，不创建各租户副本。

源定义使用稳定的算力市场资源标识，安装时映射本地模型 ID；模型未同步、未上架或规格不再支持时明确拒绝同款，不切换为其他模型。用户同款新增独立草稿和素材权限记录，不提交生成、不扣算力。

只接受原记录中授权、持久化的公开对象存储素材，禁止本地文件和私有/临时签名链接。平台登记完整存储坐标和公共 HTTPS 访问地址，不复用其他租户凭证、不下载或重传素材。内置模板引用过的对象保留共享保护；删除原记录或下架模板仅影响记录。修订、下架和删除保留历史素材引用，避免已有用户草稿失效。OSS 的外部清理、过期策略也必须排除此类共享素材。

# 探店视频 frontend contract

This application uses the shared backend runtime and production frontend builds delivered by system 1.0.440 or later. Upgrade the system before installing this application package. The app package supplies its registry, migrations, menus, permissions and declared entry metadata; it does not replace shared hashed frontend chunks.

- pc: `/ai/tools/aigc_store_visit`
- platform: `/apps/aigc_store_visit/config`
- tenant: `/apps/aigc_store_visit/config`
- uniapp: `/apps/aigc_store_visit/pages/creator/index`

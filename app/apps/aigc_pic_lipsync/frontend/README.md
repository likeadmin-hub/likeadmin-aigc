# 图片数字人管理后台

此应用包包含平台和租户后台的完整编译资源，不修改 PC、H5 或小程序用户端。
运行文件、权限、菜单和安装迁移都由应用包安装器部署。管理后台需刷新浏览器后使用。
本版本与系统 1.0.388 的后台资源和运行接口匹配，安装器会阻止在其他核心版本上覆盖资源。

平台安装应用后，可在应用中心管理开通套餐；租户在应用市场开通并上架。
生成模式、成本和售价在现有算力市场中维护。
形象和音色与现有数字人素材库共享；管理页面会提示共享关系。
软卸载保留任务和素材。清理卸载取消未完成扣点预留，并清除本应用配置、任务、作品和驱动音频记录，保留共享形象、音色和结算账本。

公共音色使用已保存的参考音频；保存或分享音频不会创建音色克隆任务。

# 角色、场景与镜头素材关联

## 行为与兼容边界

新生成的分镜图片和视频记录生成时相关角色、场景的视觉依据。修改外观描述、角色主图、三视图或场景图片后，镜头制作面板列出受影响的镜头及原因，支持定位后使用现有生成操作更新素材。

- 依据保存在生成任务 `request.visual_dependencies`，版本为 1；按主体、场景稳定 ID 关联，只包含内容指纹和名称，不使用修改时间推断。
- 剧本详情增加可选的 `visual_dependency_catalog`，从当前可见计划只读计算。前端缓存与工作区一起隔离；切换项目时清除，刷新后重新核对。
- 视频及引用分镜素材的生成任务继承输入素材的依据。使用旧分镜图生成新视频，不会抹掉旧图与当前角色或场景的差异。
- 新素材选中后按其自身生成依据判断；重新选回旧素材仍会显示差异。修改无关角色不影响没有引用它的镜头。
- 旧任务、上传素材、无法确认的名称关联以及缺少上游依据均视为未知，提示人工核对。不会把未知自动判定为失效，也不补写伪造的历史依据。
- 所有既有素材、选中项和成片保留。复查提示不自动生成、不扣费、不阻止继续使用旧素材或导出。成片仍可下载。
- 没有数据库迁移、客户数据批量回写、权限调整或展示配置修改。画布工作流和声音策略未更改。

## 接口与实现边界

字段只用于创作复查。后端以构造生成请求时读取的计划和真实输入素材计算依据，不接受客户端提供的依据快照。上游素材及任务查询同时限制租户、用户、项目和未删除状态。传给视频供应商前移除内部依据字段，不改变供应商参数或计费。

当前仅跟踪角色/场景视觉内容。镜头文字变更继续使用已有比较逻辑；历史素材缺少依据时不能自动还原当年的创作状态。新旧前后端混合部署时可选字段缺失将降级为人工核对，不影响播放、选择或导出。

回退仅需回退两仓库对应源码提交；历史记录中的新增可选字段可保留，不需要清理数据库或文件。

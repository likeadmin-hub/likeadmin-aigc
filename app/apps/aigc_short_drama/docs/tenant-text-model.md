# 租户短剧文本模型

租户后台「AI短剧 → 基础配置 → 短剧文本模型」使用现有 default_text_model_id 配置。新建剧本、上传剧本、修订、画布对话及直接文本节点由服务端读取当前租户配置；浏览器、账号偏好与 Skill 中的文本模型选择不再覆盖它。图片、视频模型仍可由用户选择。

已入队的剧本任务及画布执行快照保留原模型；重试不会因租户配置变化换模型。配置的模型下架时明确失败，不自动转到其他付费模型。未配置的旧租户保持现有默认解析行为（现有租户配置、平台配置及可用模型默认值），管理员保存后固定为所选模型。视觉文本模型独立用于参考图理解；配置的创作文本模型处理图片仍需具备视觉能力。

不新增表、权限或接口，应用禁用、租户隔离、扣费与存储仍使用原有校验。回滚需同时还原两端源码；现有配置字段和历史任务无需迁移。

# 单集制作与导出约定

本轮覆盖常规单集及分集内复用的制作工作台。按用户要求，不增加步骤引导或“下一步”文案，仅展示任务及素材状态。
画布 Agent、跨集剧情编排、模型选择和计费规则保持原有约定。

## 导出输入

现有生成接口的 `export_video` 请求增加可选的 `params.timeline`：

```json
{
  "timeline": [
    { "shot_id": "1", "asset_id": 123, "duration": 8 },
    { "shot_id": "2", "asset_id": 124, "duration": 3 }
  ],
  "bgm_enabled": false,
  "bgm_asset_id": 0
}
```

- 时间线必须与当前任务下的分镜数量、顺序一致；每一项使用服务端授权的素材编号，不接受客户端素材 URL。
- 校验租户、用户、项目、素材状态、镜头归属和时长后，服务端将选用结果保存到任务请求中的 `_export_timeline`。客户端不能直接设置此字段。
- 排队、执行和重试使用这份快照。素材被删除时明确失败，不自动换成另一份结果。
- 有配乐选项时按用户指定的启用状态和素材导出；省略选项的旧请求继续使用历史默认行为。
- 未提交时间线的旧客户端继续按已选素材及历史回退逻辑构建时间线。已有排队任务没有快照时保留旧执行路径。
- 成片素材元数据中的 `export_timeline` 用于提示当前时间线是否已变化。旧成片没有快照时提示用户核对，不判断为最新或过期。
- 不新增数据库字段、权限、端点或计费规则。快照保存在已有 JSON 字段中。

## 修改和恢复

- 工作台对比素材所属生成任务的分镜快照与当前分镜，提示视觉内容、引用或视频对白变化；不删除、不自动重做素材。
- 项目改名和素材选择不会使所有镜头过期。上传素材或缺少生成快照的旧素材不自动判断新旧。
- 本轮不自动传播角色外观变化，也不改写后续集；素材变化检测仅覆盖有生成快照的分镜内容。
- 素材读取失败保留上次数据并重连；导出进度读取失败不当作任务失败、不再次提交。
- 切换项目或集数后，旧范围的异步读取结果不写入新页面。隐藏页面停止轮询。
- 重新打开项目可从制作进度查看导出任务和下载结果。成片完整性检查支持图片和视频混合时间线。

## 验证与回退

仅在包含最新 feature 提交的本地 develop 上执行：

- 后端：`vendor/bin/phpunit tests/Feature/ShortDramaExportTimelineTest.php`，并回归素材选用和 FFmpeg 音视频时长测试。
- 前端：生产状态、恢复、时长、素材读取、阶段衔接及组件编译测试。
- 用合成素材和模拟请求验证，不调用付费模型或改写业务数据。
- 真实供应商耗时、费用基线及真人完整创作验收仍需在指定测试账号下单独执行。

上线应先更新后端再更新前端，旧后端不会识别新时间线选项。回退优先回退前端；已创建的新快照任务应使用支持快照的后端处理完成，再考虑回退后端。无需数据迁移或删除历史素材。

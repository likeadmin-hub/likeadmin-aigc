# 视频效果配置与验证

静态页面 91 条记录按演示素材去重为 90 个效果；重复项为 Outfit check/outfit_check。原分类保留。
`reference-review.json` 记录逐个视频的时长、观察结果与分析方式。分析覆盖每个视频全时段的十个顺序画面；火焰、故障和列车效果额外用每秒六帧检查。指令为依据观察原创编写，不是参考站的服务端提示词。

- 镜头类区分摇摄、平移、光学变焦、移动变焦、升降与环绕。
- 动作类写明预备、发力、运动、结束姿势和肢体连续性。
- 特效类写明产生位置、发展路径、遮挡关系和结束状态。
- 六个明确切换目标画面的效果（火焰、烟雾、立柱、标志、渡鸦、魔法流动）只允许首尾帧。
- `data/video_effects.json` 是源预设，默认启用、无模型绑定；未保存效果配置的租户自动获得默认目录。已保存的关闭状态、空目录、自定义效果不会因升级被覆盖。
- 选择效果自动填充适配模型、生成方式和效果提示词。场景输入仅在为空或仍是上次自动填入的内容时更新。效果提示词可以编辑，保存到任务快照并在重试/再次创作时恢复。
- 默认预览不上传为用户参考素材。效果列表只为可见区域加载视频。

导入脚本 `scripts/import-video-effects.php` 默认只校验。明确传入租户、商品模型、已下载的素材目录及 `--apply` 后才上传素材中心并保存。重跑会替换同标识预设、保留自定义效果及已有托管素材，并复用按内容散列命名的素材记录。素材文件需命名为效果标识加 `.webp` / `.mp4`。

本轮用户要求不消耗算力：自动验证只覆盖配置、输入校验、指令编译、模型请求构造与页面交互。90 个效果均没有进行真实模型输出质量验收，复杂变身、肢体动作、文字/Logo 保真和长镜头应由用户试生成后调整；不保证与参考演示逐帧一致。

Before importing into an existing installation, apply `app/apps/aigc_video/migrations/upgrade_20261012_effect_config_capacity.sql`. The configuration field uses MEDIUMTEXT to retain the full catalog; fresh installs include the same type. New tenants share this table.

完整模板：`template` 保存默认模型、生成方式、场景提示词、时长、比例、清晰度和参考图片（含首尾帧用途）。旧效果没有此字段仍按原交互使用。选中完整模板替换编辑区的场景与素材；点击图片替换只变更该图，不改效果指令或参数，上传失败保留原图。

`scripts/configure-video-effect-templates.php` 可给已有目录补全模板。输入目录包括 `recipes.json`（id、generation_method、duration、ratio）与 `ID-first.jpg`，六种转场还需 `ID-last.jpg`。本次默认素材来自已有演示视频的首画面和结束前 0.12 秒画面，时长取最接近的模型可用整数秒，比例取最接近的可用比例；图片在素材中心托管。默认先校验，`--apply` 才入库；不提交生成。演示素材不代表当前模型实测结果，原站隐藏配置无法据此还原。

模型兼容性更新：`product_ids` 仅兼容旧数据，不再作为效果模型白名单；模板 `product_id` 是默认模型，不限制用户改选。前端改选模型时按生成方式、参考素材和当前规格检查，不兼容则清除效果及隐藏指令并提示。前端不再展示效果提示词输入区，后台仍可管理指令。

## 平台统一托管默认演示素材

平台执行一次 `php scripts/migrate-default-video-effect-media.php --media-dir=/path/to/video-effects --apply`，将 90 个默认效果的 180 份封面/演示视频存入平台当前存储，登记到平台素材中心。文件目录格式为 `ID.webp` 和 `ID.mp4`。省略 `--apply` 仅校验、不上传、不修改配置。没有本地素材时可用 `--download --apply`，仅下载目录内审核过的 HTTPS 来源，限制大小、超时并校验 MIME。

脚本按内容散列复用平台文件、逐项记录进度，失败后可重跑。租户共享平台默认预览，不复制到租户素材库、不改租户配置和参考图。旧配置中的默认外链自动映射到平台素材；租户替换过的 URL、主动清空的预览、开关和模板参考图均保留。云存储签名在读取时刷新。

首次安装和现有安装使用同一默认目录及平台登记表，无需新增数据库结构。源码不包含上传文件、存储凭据或本地数据库记录。默认目录直接使用系统已托管的公开预览；没有本地平台登记表的安装也使用同一托管地址，不再回退到参考网站域名。需要转存至当前安装存储时再显式执行素材迁移。此迁移不发布版本、不调用生成模型。

旧租户配置通过 `data/video_effect_legacy_media.json` 中按效果、字段保存的 SHA-256 指纹精确匹配，再映射到当前默认目录；它只保存旧地址的识别指纹，不包含外链。匹配不改写租户配置；自定义地址、预览留空、停用状态和模板参考图继续保留。当前安装已登记的平台素材优先，读取时仍刷新云存储签名。不要删除兼容指纹表或对自定义媒体进行批量替换。

## Pixlr Ads 场景模板（租户主动导入）

`app/apps/aigc_video/data/pixlr-ads.json` 为 2026-10-12 在 Pixlr Video Creation → Ads 可见的 60 条演示素材清单。中文场景方向为重新编写，不是原站完整提示词或隐藏参数；原演示并非本站模型实测输出。此批不是默认目录替换，不自动分发到其他租户。

1. 在本地 develop 执行 `python3 scripts/prepare-pixlr-ad-media.py --media-dir=/path/to/pixlr-ads`。需要 ffmpeg/ffprobe；仅允许清单 CDN HTTPS 地址，拒绝跳转，每份视频上限 80 MiB、网络和解码均设超时。提取首个解码帧为 JPEG，记录尺寸、时长和 SHA-256。
2. `php scripts/import-pixlr-ad-templates.php --tenant=1 --product=98 --media-dir=/path/to/pixlr-ads` 先校验；加 `--apply` 上传到该租户有效存储、登记素材库、备份配置并追加保存。目标模型必须支持图生视频、768P、自适应比例及可枚举时长。使用最接近演示时长的可用值。
3. 所有新增项归入 Commercial/Ads，封面与默认参考图使用同一首帧文件，默认启用；现有 ID 不覆盖，重跑按文件散列复用素材。租户可修改或删除；导入仍需显式执行，删除后重跑会重新添加该批缺失项。
4. 保存前校验配置没有并发变化，出现变化时保留已上传素材并中止配置保存。每次执行后检查回读；未调用生成接口、不扣算力。来源素材的使用及分发授权由部署方核实，来源记录不等于授权证明。

媒体文件、运行配置备份、存储地址不提交源码。其他环境须执行同一素材准备/导入过程；不会随源码推送同步本地租户配置。

素材准备和导入均读取当前激活的运行版本；已有安装不会回退到旧站点app目录。升级尚未完成时素材准备会阻止执行。导入前可用PHP 8.2运行 php scripts/import-pixlr-ad-templates.php --check-runtime，仅核对运行目录、模板数量及服务类来源，不上传文件、不修改配置或调用模型。

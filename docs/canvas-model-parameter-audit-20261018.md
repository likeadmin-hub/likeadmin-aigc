# 无限画布图片/视频模型参数核查（2026-10-18）

## 无声视频根因

对原任务保存参数与计价快照进行离线重建：未设置生成音频时，画布规范化代码补入 `generate_audio: null`，共享视频适配器把 null 转成布尔 false，最终向 Wan 3.0 发送 `parameters.audio: false`。输出文件探测只有 H.264 视频轨，没有音频轨。修复为未填写时保持省略，显式 true/false、0/1 和字符串布尔值按原意校验并提交。已经生成的视频不会因此增加音轨，需要重新生成。

## 对照来源与范围

通过当前系统已有算力市场客户端只读获取 https://api.likeadmin.cn/ 的模型列表和应用详情，核对 13 条图片模型、6 条视频模型、6 份应用接口，共 25 份公开契约。脱敏 fixture 仅保留公开模型名、参数 schema、默认值，不含账号、密钥、价格或任务内容。

| 类别 | 核查对象 |
| --- | --- |
| 图片模型 | Nano Banana 2.1、Nano Banana Pro、Nano Banana 2；GPT Image 2.5 Sunburst/Flare/标准版、GPT Image 2 VIP/Pro/Fast/标准版（两个渠道）；Qwen Image 3.0/Pro |
| 视频模型 | Wan 3.0 Video、VEO 3.1 Pro/Fast、Grok Video、Q4 Preview、H3 |
| 市场应用 | Nano Banana、Seedance、Wan、Grok Video、Happy Horse、全能视频 |

本地已启用图片目录共 20 个入口、561 个规格组合，视频共 11 个入口；未擅自启用未上架模型。

## 接通与约束

- 图片/视频高级参数面板读取模型契约，按模型分别保存、恢复默认并提交 `advanced_params`。覆盖布尔、整数、数值、枚举、文本、JSON、工具数组、嵌套 metadata 和图片 URL/上传控件。
- 接通遮罩 `mask_url`、图片质量/透明背景等已声明字段；不混同计费分辨率和图片质量。
- 接通视频音频开关、随机种子、提示词增强、水印图片/位置、帧数/草稿/镜头设置、服务档位、联网搜索、Wan 音频策略与业务标识、业务关联数据和 JSON 元数据。
- 保留已有图片、视频、音频参考、首尾帧和多模态生成模式的原有映射；模型、计费 SKU 和规格锁定沿用原有选择器。
- 回调地址仍由系统管理；不作为普通用户可修改参数。未发现的未来字段不会任意透传。
- 未填写与 false/0 分别处理。非法输入恢复原值并显示错误；JSON、工具、图片地址等在前后端校验。Seedance 联网搜索仅允许文生视频，含参考素材时在扣费前拒绝。
- 上传期间切换模型不会把图片地址写进新模型参数。

## 验证

所有测试和运行均在已合并最新功能提交的本地 develop 执行；源码编辑/提交位于 feature/agent-optimization。

- 新增离线全目录契约：25 份接口，221 项字段和实际提交值检查通过。
- 既有高级参数契约：24 项通过。
- 图片目录：20 个入口、561 个规格组合通过。
- 视频生成模式与应用契约通过。
- 共享图片/视频负载与能力测试：52 个测试、240 个断言通过。
- 前端参数测试：15 个通过。
- 浏览器使用专用验收画布，检查音频开启/关闭、刷新保存、模型参数隔离、种子 0 和联网搜索控件；不调用付费生成。

测试范围为实时市场公开契约、离线实际负载构造和本地 UI。没有逐模型发起付费生成，供应商最终输出质量及音轨仍以实际生成结果为准。

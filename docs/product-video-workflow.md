# 商品视频创作工作流

功能以独立应用提供，继续使用系统工作台、主题、租户权限、算力市场及实际用量结算。

- 普通模式：商品图 → 直接描述或原创展示模板 → 确认视频规格及费用 → 后台生成。支持描述优化、首帧和可选尾帧。
- 高级模式：商品图与确认资料 → 一次智能分析生成商品信息、展示重点、连续镜头和完整视频描述；故事板预览按需勾选 → 结果原位回填 → 编辑并确认 → 生成视频。也可直接填写描述。
- 参考分析：上传视频或导入可下载的媒体地址；按实际画面和声音提供观察，不移植参考商品事实。
- 商品来源：本地上传、自有素材、商品资料库、受支持的公开商品页元数据导入。页面受限时退回上传，不绕过登录或反爬。
- 生成素材：图片、视频、音频角色及稳定槽位跟随模型原生能力。删除已引用素材时要求修正描述；更换商品后重新确认描述或更新方案。
- 结果：视频、故事板、文字结果、阶段进度、费用、下载、再次编辑。再次编辑从提交快照建立新草稿，不覆盖原稿。
- 成片章节：可在视频提交前选择自动分析，也可完成后单独分析；按真实视频而非计划时间生成章节。分析失败不影响视频播放。

## 明确边界

视频分享页面解析本轮不做；视频理解模型接收的是视频内容，不是任意分享页。模板和文案为本项目独立实现，不包含参考站品牌、图片或私有提示词。

错峰服务仅可由算力市场的供应商规格、费用与调度合同提供。本应用不硬编码参考站的折扣、优先级或等待时间，不向用户展示未接通的优惠开关。

## 数据与执行

草稿乐观版本校验；报价绑定稳定素材、模型、费率及输入快照；单次报价不能重复消费。阶段子任务受唯一键约束，重复刷新不重发。文字阶段完成而图片阶段失败时保留可采用的文字结果。费用不明或受理不明保留原任务核对，不自动创建新任务。

涉及的安装来源包括应用迁移、完整安装 SQL、升级 SQL、应用注册及共享/独立租户初始化；配置同步保留租户自有选择。只交付源代码。

## 验证范围

本地事务测试覆盖租户与用户归属、草稿冲突、报价、幂等、两阶段分析及部分成功、历史快照、回调归属、成片章节去重；音视频验证用本地生成的临时文件。测试不调用付费模型。真实供应商生成效果、商品页登录或地区限制仍需实际环境验收。

## 工作台统一与辅助结果

PC 沿用系统介绍/历史创作、统一任务卡、素材选择器和视频提示词编辑器。底部始终提交视频，识别、优化和规划在左侧独立触发并显示进度。完成后仅向未修改的同版本草稿自动回填；发生人工编辑或版本冲突时保留原内容，可从请求快照与结果创建新草稿继续。中间记录保存在可展开的辅助记录中。

故事板默认不生成，不依赖可用图片模型才能规划文字镜头。主动生成故事板时展示额外费用，视频提交报价明确说明是否实际附作模型参考。自动/手动成片章节任务均归属原视频卡，处理中禁止删除父视频，不向辅助历史混入章节子任务。

兼容已有请求：不带历史分组参数仍返回原列表；新分组仅筛选显示；不带 include_result 的再次编辑仍仅复制提交快照；已提交并报价的两阶段分析继续执行原快照。

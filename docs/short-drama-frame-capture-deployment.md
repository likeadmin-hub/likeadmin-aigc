# 短剧画布截帧部署与验证

## 运行要求

- FFmpeg 必须安装在运行 `ai:task-worker` 的主机或容器内。宿主机安装不代表 PHP 容器可用。
- Debian/Ubuntu 可使用系统软件源安装：`apt-get update && apt-get install -y --no-install-recommends ffmpeg`。容器重建时应由镜像构建或部署步骤重新安装，不能只依赖现有容器的临时修改。
- 使用实际后台进程用户检查 `ffmpeg -hide_banner -version`；非 PATH 安装可设置 `FFMPEG_BINARY` 为可执行文件绝对路径。
- Worker 使用的 PHP CLI 须允许 `exec`、`proc_open`、`proc_get_status`、`proc_terminate`。不要因此全局关闭其他安全限制。
- Worker 需要读取源视频、写入 `runtime` 临时目录，并能使用租户的素材存储配置读写文件。对象存储视频需要网络访问权限。
- 运行项目已有的 `scripts/start-ai-task-worker.sh` 或已有 Supervisor 配置。部署 PHP 代码或修改环境变量后，平滑重启已有 Worker；不要重复启动第二套进程。

## 任务与重试

1. 点击当前帧、首帧或尾帧后，先保存画布，再提交异步截帧任务。
2. 正在处理或已成功的相同视频/时间任务复用原任务。查询状态不会重启任务。
3. 截帧失败后，修复运行环境，再点击截帧会创建新尝试。旧失败记录及错误信息保留；无需清空任务表或手动修改用户画布。
4. 自动视频封面任务维持原有行为，不随画布保存自动复活已失败任务。
5. 音频轨或容器时长略长于视频画面时，若请求时间未解码出图片，则在请求时间之前最多一秒范围内取最后有效画面。解码失败和明显越界仍返回失败，不用首帧替代。

## 验证

开发工作区须先将 feature 提交合入本地 develop，并只从 develop 执行：

```sh
php app/apps/aigc_short_drama/tests/canvas_toolbar_integration.php
php app/apps/aigc_short_drama/tests/canvas_frame_media.php
```

- 第一组检查任务幂等、显式失败重试、旧错误记录保留、租户/用户隔离和封面状态；数据库测试数据回滚。
- 第二组使用 FFmpeg 创建临时视频，检查首帧、当前帧、尾帧、音轨长于画面的边界和越界失败；不写数据库或素材存储，临时文件自动清理。
- 页面验收：选择一个已保存视频，分别截取首帧、中间位置当前帧、尾帧，确认新增图片可见、画面不同，刷新后仍可加载。再核对任务成功状态、图片尺寸及存储元信息。
- 本次本地验证：FFmpeg 5.1.9，三种截帧均成功，实际图片为 854×480，使用租户对象存储，刷新后加载正常。此记录不替代线上环境验收。

## 变更边界与回退

本次无数据库结构、接口参数、权限、计费或前端源码变更。回退相关 PHP 源码后需重启 Worker；保留已生成图片和任务记录，不需要删除租户数据。

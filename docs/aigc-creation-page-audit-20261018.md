# AIGC 图像/视频创作页核查

范围：PC `/app/aigc_image`、`/app/aigc_video`，对应服务与共享市场目录。沿用同日从算力市场获取的 25 份公开模型/应用契约。没有新增接口、权限或数据库迁移。

## 已修复

1. 独立创作页缺少高级参数控件，提交只包含基础规格。现在读取市场参数定义，按模型分别保留当前编辑值，估价与生成使用相同的 `advanced_params`，服务端在生成任务和扣费前验证、转换；保留 false、0、JSON、嵌套字段和工具数组。
2. 视频页无法明确选择首尾帧、参考图、视频编辑等方式，且匹配失败时静默退回首个 SKU。现在只展示市场支持的生成方式，自动方式根据素材和能力推断，选择匹配规格；找不到匹配规格或缺少素材时提示并阻止提交。
3. 图像页只列出 12 个模型入口，遗漏 8 个 Nano Banana 应用变体。目录现在包含全部 20 个已启用入口，保留应用变体编码，使用各自的市场运行器和 SKU。
4. 部分图片规格名称重复，无法辨别 1K/2K/4K；视频历史分辨率误加“秒”。修正展示标签。
5. 创作栏吸顶且内容过高，底部控件难以操作。两个页面加入独立滚动区域，保持基础规格、高级参数、生成按钮顺序。
6. 估价错误原先被静默忽略。现在显示具体错误；视频页对于不支持的素材/生成方式组合停止估价并禁用提交。Q4 图生视频允许不填提示词，但仍要求匹配素材和规格。

## 验证

- 新增独立创作参数离线契约：25 份定义、221 项字段与提交值检查通过；没有调用生成供应商。
- 新增图像创作目录检查：20 个入口均经过实际服务选型与只读估价，产品及 SKU 一致。
- 创作页与画布前端回归：20 个测试通过，包括两个 Vue 页面的编译、估价/生成参数一致、false/0 保留、指定生成方式不回退错误 SKU。
- 画布既有 221 项参数检查、20 个入口/561 个图片规格组合检查、视频生成方式检查通过。
- 图片批量提交回归：5 个测试、86 个断言通过。
- 浏览器：图像页完整目录、分辨率标签、画质/透明背景设置；视频页 Wan 音频开启、生成方式选择、缺少首尾帧素材提示；两个页面高级参数操作后均无估价错误。

此次没有新增付费生成、删除作品或改动既有任务。供应商实际生成效果、逐模型音轨与媒体质量未通过付费请求逐一复测。

源码回滚：分别回退本次功能提交；无需回退数据库。新增高级参数为可选，旧请求保持兼容。

# 装修模板资源迁移

租户端「装修管理 → 模板管理」沿用原有导出、导入入口和 `.ladtpl.zip` 格式。导出文件保持 schema 1.0，旧版包仍可导入。

## 导出

- 模板封面、设置、页面各版本内的图片、图集、CSS、富文本和媒体地址转换为完整 HTTP(S) URL，保留组件布局、裁剪、热区坐标等配置。
- `assets/resources.json` 记录资源 URL 及引用位置。同一地址只登记一次。
- 私有资源和带签名的资源同时放入包内，并记录内容哈希、类型与大小；导入优先使用包内字节，避免来源签名过期。
- 导出不会发布模板或改变当前启用模板。生产环境须配置可供客户访问的站点/存储域名；开发环境的 localhost URL 不能供其他客户远程下载。

## 导入

- 按当前租户的有效存储配置转存素材，创建属于当前租户的文件记录，并改写模板地址。同一内容只上传一次。
- 删除来源租户的素材身份，按目标文件重新建立身份。私有目标资源持久化稳定路径，读取时生成新的访问签名，编辑保存时去掉签名。
- 新模板为未启用草稿，保留草稿、已发布内容及页面结构；经预览、发布、启用后对用户生效。
- 任一素材失败则回滚模板和本次文件记录，补偿删除本次独立目录的文件。清理失败时在 `runtime/decorate_import/` 留下无密钥修复记录。
- 来源外链必须可下载。外部 URL 逐跳验证公网地址并固定 DNS 解析结果；本站上传资源须属于当前租户。

## 边界

- 最多 128 个资源地址，单文件 20 MB，累计下载 100 MB，单次资源处理预算 60 秒。
- ZIP 原始与累计展开内容均不超过 20 MB，最多 512 个条目和 256 个页面。
- 按真实字节验证媒体类型，SVG 清理后再存储。无法读取、类型不支持、包内哈希不匹配或超限时明确失败，不创建缺失素材的模板。
- 应用入口、业务链接和事件仍使用现有功能配置；资源迁移不会安装应用或转移业务数据。

## 本地验证

```sh
PORTABLE_INTEGRATION=1 sh tests/decoration/run-local.sh
```

集成测试仅允许本地 `z_cn` 数据库和本地存储，使用事务夹具并清理物理副本；包含真实模板跨租户导入、布局不变、私有签名刷新、再次保存、失败回滚及旧版包兼容。

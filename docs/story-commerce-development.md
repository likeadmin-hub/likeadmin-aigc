# 剧情带货

1. 独立应用 aigc_story_commerce，统一创作流程，不含普通/高级模式。
2. 剧情类型为应用配置，画风读取当前租户已启用短剧画风；服务端冻结规则与画风快照。
3. 剧情分析一次返回商品事实和文字脚本；视频按所选原生规格生成一次，不承诺逐镜生成拼接或精确多角色口型。
4. 新任务通过 ai:task-worker 的 story_commerce 作业处理。首次部署除让进程加载处理器外，还必须确保至少一个消费者可以领取该应用；仅运行 `--app=aigc_pic_lipsync` 不会处理剧情任务。推荐独立常驻进程 `php think ai:task-worker --app=aigc_story_commerce --sleep=2 --batch=1 --lease=600`（Supervisor 或服务管理器，PHP 8.2；修改后仅加载该进程）。初始原生作业尚无 app_task_id/consumption_id，按任务类型、生成的幂等键及未删除的原生记录绑定领取，不扩大到其他应用。无付费模型自动重发。
5. 应用表、接口、菜单、权限、四端入口和报价均独立；引用统一模型、计费、托管存储及资产机制。
6. 随系统内置的默认应用沿用现有卸载保护，不提供绕过删除；清理适配器保留审计且不删除物理素材。

验证：tests/story-commerce-policy.php；本地流程测试须限定本机 x_cn 并回滚测试行，不调用付费模型。

回退：回退本应用及对应适配器的源码提交；保留应用业务表、计费审计及物理素材。不要执行删除数据或版本发布脚本。

PC 交互调整：剧情类型下拉选择、自定义使用弹窗；画风沿用工具选择器的卡片布局，使用 1:1 正方形封面和标题，封面由租户后续配置；销售地区采用商品视频分类并隐藏独立标题；剧情脚本是直接输入和 AI 回填的单输入框。持久化 script 字段兼容文本及旧的结构化脚本，文本脚本不强制用户填写镜头时间表。租户的剧情类型与编剧规则由独立标签和权限维护，创作配置保存不覆盖该规则。

画面风格支持内置“无风格”（style_id=__none__，快照 mode=auto），不依赖租户画风库或封面，不代表禁用视觉设计。未配置默认风格时新草稿默认无风格；已有预设、自定义和历史快照保留。分析接收用户补充要求及已有脚本：无风格时优先采用其中的风格描述，否则 AI 根据剧情与商品设计；生成使用同一已确认脚本且不追加预设提示词。模板与记录复用保持该语义，无新增表、接口或权限。PC 素材点击直接放大，保留脚本内 @ 引用；数量按当前模型纯图片模式的真实上限，要求额外视频/音频的模式不计入。

# 无限画布门户配置

无限画布首页及模板页读取同一租户的门户展示配置。首屏背景由网站设置维护；模板/灵感卡片通过无限画布应用的模板管理维护。两入口分别发布各自栏目，使用同一修订号防止并发覆盖。封面只接受当前租户素材中心的有效图片/视频记录，URL 由存储服务解析，不接受任意客户端媒体 URL。

新增租户管理接口：`app.aigc_canvas.template/detail`、`app.aigc_canvas.template/publish`，均有对应权限、API 声明及菜单；发布权限为独立操作权限。PC 公共网站配置只返回已启用卡片。无新业务表，也不改动项目、节点、计费或任务状态。

升级源：应用迁移、根 upgrade SQL、新安装 SQL 和新租户 SQL 均包含模板菜单。已有分表租户需通过现有 `AppMenuService::syncTenantMenus($tenantId, 'aigc_canvas')` 同步其菜单；应用注册安装流程也会执行这一同步并注册 API。该过程不要授权原本没有模板发布权限的普通管理员。

本地已同步当前租户的菜单和两项 API。`tests/home/canvas_portal.php` 通过：租户隔离、素材类型/归属、删除后隐藏、启用筛选、显式空目录、修订冲突及分栏目保存。测试使用事务并回滚所有配置和素材变化。

不涉及付费生成、付款或项目数据删除。模板使用仍是预览，Agent 输入仍是前端独立草稿。

### 首页背景动画与素材
- 现有 hero 配置新增 enabled/items；单素材旧配置在读取时转换，显式空列表不会重新显示旧素材。
- 仍通过原网站配置接口发布，只更新 hero，不改变模板。图片/视频及封面逐项校验租户和类型，通过统一存储服务解析地址，上限20项。
- 不新增表、路由或权限；事务回滚测试覆盖开关、空列表、混合素材、旧配置与非法素材。
- 验证：tests/home/canvas_portal.php事务回滚测试通过；后台真实图片/视频配置发布、前台刷新读取、开关发布和清空恢复实测通过。未改项目数据或触发付费生成。

## 当前边界

已实现独立的 VNext 核心、增量表、固定响应执行测试和普通短剧页面的快照读取组件。**新建用户任务仍走原有引擎：尚未加入创建任务的 VNext 路由，也没有开放新流程默认流量。** `JobRunner` 目前由行为测试调用；现有任务详情只有在服务器保存的请求显式标记 `_pipeline_version=1` 且存在对应作业时才返回 `generation_snapshot`。

因此，以下测试通过不表示当前用户实际生成已完成重构，也不表示整体生成成功率已达到 95%。没有执行真实付费模型请求、200 次基准或发布操作。

## 已实现及证据

| 能力 | 实现 | 已覆盖行为 |
| --- | --- | --- |
| 规范正文 | `vnext/ContentDocument.php` | 系统分配单元身份；重复相容实体合并；同名人物使用独立短别名；冲突拒绝；阅读内容从正文派生 |
| 原文追溯 | `vnext/SourceTrace.php` | 原文哈希及版本；Unicode 码点范围；分段拼接不漏字；要求到事件的一对多关系；确认集段漏分配检查 |
| 分镜编译 | `vnext/ShotCompiler.php` | 引用完整性、对白先后和尾句覆盖；多个画面引用同一句对白只生成一个声音段；编辑使旧引用失效 |
| 覆盖核验 | `vnext/ContentCoverage.php` | 逐项检查结论；真实引文和版本验证；本集/远期范围区分；结构存在不代替模型语义结论 |
| 三阶段生成 | `vnext/GenerationPipeline.php` | 正常单集 3 次调用；每阶段格式恢复最多 1 次；局部修复预留 3 次调用；无改善/重复内容停止；保留最佳候选 |
| 上传内容保护基础 | 同上 | 已结构化且由服务器校验的正文跳过创作调用；语义核验不能擅自重写忠实原文 |
| 执行持久化 | `vnext/ExecutionStore.php` | 单集活动作业唯一；租约围栏；同一阶段输入签名；调用账本跨恢复保留；整轮修复预留；最多 2 轮 |
| 收据保存 | `vnext/ReceiptBuffer.php` | 私有文件原子提交；回放不再调用模型；数据库未写入的已有缓冲收据可恢复；未知提交不盲目重发 |
| 瞬时连接故障 | `ExecutionStore` | 明确未建立连接才进入退避；最多 2 次自动重试；读取超时保持待核对 |
| 发布基础 | `ExecutionStore` / `JobRunner` | 修订、当前作业指针与 outbox 同事务；重复运行不重复发布；取消后的迟到收据保留但不能覆盖内容 |
| 制作编译基础 | `vnext/ProductionCompiler.php` | 叙事镜头与视频片段分离；独立配音文本只生成一次；模型时长能力重编译；绑定正文、分镜、素材及提示词版本 |
| 页面状态读取 | `generation_snapshot` / PC `ShortDramaGenerationSnapshot.vue` | 执行、正文、制作三轴分离；草稿可读；后端允许操作列表；忽略旧序号及其他任务快照 |
| 迁移 | app 增量、app 安装、完整安装 SQL、根目录升级 SQL | 四张新表的列定义一致；重复执行不失败；原表不改写 |

所有新 PHP 核心位于 `app/common/service/app/aigc_short_drama/vnext/`。旧 `ShortDramaScriptGeneration`、`ContentFirstGeneration`、`UnifiedReview` 没有接入新核心，不会将两套审核链串起来。

1. **用户入口闭环**：创建任务时冻结新流程策略、模型能力及预算；通过白名单路由到 `JobRunner`；对接真实市场模型运行器的计费/成本字段。普通短剧与画布必须共用该入口，而非各建引擎。
2. **可恢复执行完整性**：增加上游任务查询/收据对账、限流恢复、显式增加预算授权、取消/恢复端点、outbox 消费及幂等投影。当前 `check_receipt` 是状态能力占位，尚未提供用户操作端点。
3. **预算与基础设施**：当前账本记录调用及收据用量，并硬限制调用次数/修复轮次；token、上游成本和用户点数的总上限及统一预留尚未接入。需要真实持久化故障注入和进程杀死测试；当前缓冲恢复测试通过预置 submitted 阶段与缓冲文件模拟数据库写入缺失。PHP 8.0 没有 `fsync` 时仅使用 `fflush`，尚未验证主机断电耐久性。缓冲还需多 worker 可达的持久卷和保留/清理策略。
4. **长文本与上传**：来源分段已实现，但长集容量规划、分场执行计划与完整附件解析链尚未接入；真实截断目前保留收据并停止，不会伪造完整结果。结构化输入跳过重写已测试，不能等同于所有上传格式已支持。
5. **完整内容修复**：当前支持保持单元身份的文本补丁；缺失单元插入、拆并、人物歧义裁决、事实矛盾裁决和忠实原文的分镜专用修复待补。重要身份冲突会停止，不会自动猜一个身份。
6. **多集事实与依赖**：要求/事件追溯已有纯领域实现，尚未接入故事设定/大纲确认接口；已发生事实、知识/信念、前集修订后的依赖失效、500 集检索以及外观/地点状态注册表待完成。

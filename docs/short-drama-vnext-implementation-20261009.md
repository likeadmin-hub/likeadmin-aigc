## 当前边界

新建文本单集任务已可通过服务器租户、模型白名单进入 `JobRunner`，在创建事务中保存版本、输入、模型与执行策略。真实工作器已接通规范正文、项目版本与任务结果的原子发布；普通页支持已保存正文阅读、停止/恢复、核对本地缓冲收据和正文修订。修订产生独立任务，复用相同正文单元身份；旧版本保持可读。

**`short_drama.vnext.enabled` 仍为 `false`，白名单为空，现有用户默认任务继续使用原引擎。** 当前允许接入的范围为新项目的文本单集，以及另行开启 `series_enabled` 后、尚未开始逐集生成且有已确认故事/大纲的文本系列；旧逐集任务、上传任务不自动迁移。两个开关均保持关闭。故事设定和大纲创作仍使用既有确认流程。新任务的执行不受随后关闭开关影响。主体图、场景图、分镜图通过现有 estimate/create/detail/retry 接口按版本分流；视频、三视图、配音和导出仍有保护拦截。制作与画布适配完整验收前，不开放默认流量。
因此，以下测试通过不表示当前用户实际生成已完成重构，也不表示整体生成成功率已达到 95%。没有执行真实付费模型请求、200 次基准或发布操作。

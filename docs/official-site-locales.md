# 官网三语文案

官网使用简体中文（zh-CN）、繁体中文（zh-TW）、英文（en）。官网配置版本 13 在现有租户 JSON 配置中增加 `translations`，不新增数据表。读取旧配置时沿用现有版本升级流程，保留媒体、导航、套餐及其他官网内容。

`translations.en` 和 `translations.zh-TW` 以空白标准化后的简体原文为键，译文为值。仅接收当前官网配置中实际存在的展示文案，忽略链接、媒体、配置标识、未知语言和无效值。原文修改后旧译文自动清理；未填写译文时前端使用系统预置译文，未知自定义内容回退原文。相同原文共用译文。

租户后台“官方网站 → 多语言文案”编辑英文和繁体译文，与现有“保存发布”一起保存。默认简体内容仍在各页面配置中编辑。品牌名称、模型名称、用户输入和套餐业务数据不由官网译文字段修改。

官网语言选择共用 PC 的 pc-locale 持久化机制，切换保留路由、租户与邀请参数。官网显式翻译组件文案，使用 data-i18n-skip 避免全站 DOM 自动翻译再次处理。

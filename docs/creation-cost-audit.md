# 创作工具预计算力核对（2026-11-11）

本次范围：PC 创作工具的金额来源、参数变化、异步报价、任务卡片；后端共用目录和提交报价。未发起任何付费生成，未调整费率或历史扣款。

## 已确认问题

- 视频共用目录的别名 SKU 可能映射到同一个真实 SKU。旧目录按**别名**计量单位缩放第一次（最短时长）报价，后写入的按次别名覆盖了实际按秒计价的 SKU。修正为每个时长均走实际准入报价，并升级目录缓存键。影响商品视频、剧情带货、微视频及调用同目录的后台/移动端。
- 本地实例剧情任务 36：720p、15秒，旧目录显示132，提交快照495，实际输出15.104秒结算499；任务22：480p、15秒，快照240，实际242。132和64是4秒目录价，不是15秒价。最终费用从结算记录读取，禁止用目录重算历史费用。
- 商品视频、剧情带货底部旧目录价不包含实际素材组合/声音开关。现在调用原 job/estimate 的只读 preview 模式，校验真实媒体归属、原生模式、规格及文本，不写项目/报价令牌/队列/账本。提交仍保存正式报价并校验令牌，preview不能提交任务。
- 两工具 DTO 新增 nullable `estimated_user_charge_points`，读取已保存的请求 quote；正常排队/运行展示预计，成功展示已结算费用，受理/结算异常仍保留待核对状态。
- 动作迁移、动作替换、产品宣传视频、智能剪辑曾在无有效报价时显示默认价/单价/0。现在显示待估算。
- 旧图片工具及动作工具存在旧响应覆盖新规格风险，部分只观察少数参数。统一观察完整可报价参数和当前登录/租户上下文，变更立即失效、延时重报、丢弃旧响应，拒绝空白/负数/非有限金额，免费0有效。

| 去水印 | 后端识别/媒体规格报价 | 保留现有估价状态，未获得报价不应解释为免费 |

## 边界

本地尚未上传到服务端的 blob 素材无法通过真实媒体准入报价，显示待估算；不会用本地文件名、配置单价推测总价。Token、AI分析、按实际成片长度结算的最终值可能与提交预估不同，按任务快照及结算账本追溯。此次核对不代表对每个模型执行了付费实测。

## 验证

`STUDIO_PRICING_LOCAL_TEST=x_cn php tests/studio-pricing-preview.php` 比较当前可用目录各清晰度/比例的最短和最长时长与原生准入报价，并验证只读预览不写任务/报价/计费数据。另运行商品视频、剧情带货本地流程、计量规则和 PC 报价相关回归。所有验证按仓库规范在本地 develop 集成后执行。

接口兼容：`job/estimate` 可选 `{preview:true, action:'video', body:{...}}` 仅返回 `{user_charge_points,notice}`，无 quote_token；旧 `{project_id,revision,action}` 正式报价协议不变，无迁移或新权限。

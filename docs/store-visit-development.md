# 探店视频（aigc_store_visit）

独立内置应用，平台、租户后台、PC 与 UniApp 小程序均有入口。复用统一模型市场、计费、异步队列、持久化存储及资产机制；应用项目、任务、报价、配置和菜单权限独立。门店和人物分别上传，二者至少各一张，总数由当前视频模型真实的图片引用能力决定。

## 创作与数据约定

- `images[].role` 为 `store` 或 `person`，`reference_slot_id` 是稳定引用标识。分析、快照、模板、复用和视频提示词保留角色及全局图片序号；提供商引用格式和应用素材角色分别处理。
- `product_info` 承载门店已确认信息，`person_info` 承载人物设定。AI 观察补充独立存储，不覆盖用户原文。禁止根据图片编造价格、地址、营业时间、优惠或评价。
- 上传、选择类型/画风、分析、编辑并确认脚本、原生规格报价、创建视频任务、历史记录及一键同款流程完整。修改素材、人物、类型、风格或规格会使旧脚本确认失效。
- 默认按可用模型身份选择 Qwen3.7-Plus、Wan 3.0 高速、无风格，不写死安装环境的模型 ID；保留租户已有明确配置。初始没有虚构的探店成片模板，后台可配置真实模板，成功视频可另存模板。
- 类型为横向选择卡片，展示封面、图标、描述和选中状态；模板紧随类型；移动端按钮将动作文字与预计费用分行。
- 小程序系统选图会暂时触发页面隐藏。选图及上传期间保持同一页面的上下文；租户/用户切换或卸载页面仍使旧结果失效，普通离页仍停用请求。不要用取消生命周期隔离的方式处理选图。

## 安装与运行

应用清单声明 45 个 API、四端入口及小程序创作/历史两个可装修页面。包内图标和封面由 `public_assets` 安装；无需复制空清单或依赖旧微视频应用。完整安装源和新租户默认应用同步包含此应用。

升级源及 `public/upgrade` 镜像：`upgrade_20261113_aigc_store_visit.sql`、`upgrade_20261113_story_commerce_presentation.sql`。保留历史已执行迁移原文。需要重新生成注册源时，在 feature 分支运行 `python3 scripts/sync-story-commerce-bootstrap.py aigc_store_visit`，检查变更后再提交；该命令会写源文件，不是只读检查。

消费者必须能领取本应用：PHP 8.2 下运行 `php think ai:task-worker --app=aigc_store_visit --sleep=2 --batch=1 --lease=600`。首次原生任务尚无消费记录，按本应用任务类型、服务端生成的幂等键及未删除原生任务绑定领取，不能扩大领取其他应用。不要重启已退役的微视频进程。不得自动重复提交付费生成以恢复未知结果。

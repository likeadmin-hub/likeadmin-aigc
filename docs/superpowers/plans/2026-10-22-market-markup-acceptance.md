# 算力市场两级溢价验收记录

验收日期：2026-10-22。范围为本地开发与真实上游联调；未发布、未推送远程 develop/master，未修改客户站点。

## 实现结果

- 平台按当前上游单价配置固定加点或百分比；租户在平台进货单价之上配置同类规则。
- 支持全局、商品、规格，以及勾选商品批量配置，优先级为规格 > 商品 > 全局。加点遵循原规格单位（次、秒、百万 Token 等），不改变计量方式。
- 原有手动价格迁移为独立规则，默认保留。低于当前进货价的手动价格禁止新提交，其他可用规格正常展示。
- 恢复平台价格使用当前上游同步价；租户恢复使用当前平台进货价。清除范围内下级规则，包括隐藏规格，并设置零溢价防止上级规则重新覆盖。
- 预览展示新旧单价、涉及数量、被清除的独立配置数量。确认提交必须使用 5 分钟内且绑定当前管理员及租户的预览凭据；价格、范围或规则变化必须重新预览。并发重复提交只生效一次。
- 应用独立售价和免费配置默认保留；租户可明确勾选跟随市场价，预览会列出已识别的应用独立配置及免费项数量。未接入市场的应用不受此开关影响。
- 模型、图片、视频、已接入应用及开放 API 复用规则，任务保存价格和规则快照；历史任务不按新价重新计算。平台自付不重复计算租户溢价；零成本查询/状态轮询保持免费。
- 单价保留 6 位小数，账户预占、实扣、退款统一按现有钱包的 2 位精度处理。文本先校验余额，按上游实际 Token 用量结算；本次没有新增文本最大用量预冻结机制。

## 安装、升级与回退

新增表为 la_power_market_price_rule。安装 SQL 已包含表结构；升级 SQL 为 upgrade/20261022_market_price_rules.sql，public/upgrade 内有相同副本。自定义表前缀应使用系统既有升级流程替换前缀。迁移将旧独立售价转为显式规则，重复执行不会在恢复后重新生成旧规则，已通过两次重放验证。

发布时需同时部署前后端对应代码并执行迁移，然后按常规流程重载相关长驻服务；本次未执行生产部署或服务重启。上线前备份旧售价表及新规则表。回退应同时回退前后端；运行期间不删除规则表或消费快照。如需要把已生效规则转换回旧版本静态售价，必须先导出当前有效价格并单独核对，不能只删表假定价格不变。

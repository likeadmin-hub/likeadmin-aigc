# 云音频时长与宝塔媒体探测修复计划

目标：云音频保存真实时长，既有零时长可安全修复，PHP-FPM 能找到宝塔默认 FFmpeg 同目录的 ffprobe。

约束：保留租户及历史存储元数据；远程读取有大小和时间上限；不生成或扣费；不改其他会话的短剧文件；客户现有二进制优先复用。

- [ ] 编写媒体二进制定位回归：显式配置、PATH、FFmpeg 符号链接同目录、宝塔版本目录、非法配置及缺失程序；先失败后修复。
- [ ] 新增共享 MediaBinaryService，接入时长检测、市场媒体校验、数字人旧检测和微视频媒体程序定位。
- [ ] 新增共享 AudioDurationService，保留安全下载和小数秒；上传前检测临时文件，云音频登记及公共音色按存储快照检测；覆盖原回归并新增保存流程回归。
- [ ] 编写默认只读、显式 --apply 的零时长修复脚本，先写私有备份、再按原 URI 和零时长条件更新；验证重复运行无修改。
- [ ] 独立审查、提交、合入隔离的本地 develop，运行相应回归及 PHP 语法检查。
- [ ] 客户站点备份及最小文件发布；为现有 ffprobe 配置可发现链接；执行先只读后写入的数据修复；验证 PHP-FPM、云音频预估和零时长剩余数量。

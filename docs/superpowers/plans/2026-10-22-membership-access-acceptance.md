# 会员套餐删除与应用订阅提示验收

2026-10-22，本地开发与验收完成，未发布或推送远程集成分支。

## 修复

1. 套餐存在订单时原代码只停用却提示删除成功；现在加锁软删除，后台与购买列表移除，保留历史订单、套餐关联记录和已购权益快照。未支付旧订单的历史权益读取兼容已软删除套餐；新购买不能引用已删除套餐。沿用既有 delete_time 字段，无新增迁移。
2. 应用服务层仅检查租户是否开通时，原来还以 userId=0 检查会员，导致订阅用户也会被图片数字人等服务误报“未开通或未上架”。新增明确的租户可用性检查，用户订阅仍在 API 中间件强制校验。只读 GET config/detail 可用于展示页面；POST、私有 GET 历史等仍受保护。
3. PC 与移动创作页复用权限状态。未订阅显示“当前会员需订阅包含此应用的套餐后使用”，禁用生成并提供会员入口；查询失败时禁止提交并提供重试。切换账号、租户或应用不会使用旧权限响应。三种数字人、生图/视频与已接入的工具创作页同步处理。页面继续展示和编辑，已订阅后刷新恢复可操作。

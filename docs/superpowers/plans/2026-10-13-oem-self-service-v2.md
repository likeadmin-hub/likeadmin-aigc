# OEM 自助贴牌租户开通实施计划

权威规格：本次用户批准的《OEM 自助贴牌租户开通开发计划》。交付为现有平台内独立租户。

## 全局约束

- 客户先付款；无额度也可付款。租户审核、采购预占后提交平台，平台确认，独立执行器交付。
- 微信 Native 二维码，保留支付宝网页支付；服务器金额、验签回调和服务器查单是付款依据。
- 历史订单保持流程版本 1；版本 2 按销售租户启用，新开租户默认无销售资格。
- 默认基础版、专业版、企业版，365 天，稳定编码幂等补齐，草稿未上架，价格权益未配置。
- 成交快照不随套餐修改；额度仅在交付成功时消耗。未支付 30 分钟关闭；已付款冻结持续保留。
- 开通前拒绝全额原路退款，退款结果确认后释放额度。固定退款单号、重复交易独立退款。
- 付款 24 小时提醒，每天一次人工处理；不自动退款。续费不重复创建租户，不中断业务。
- 租户交付前禁用；执行租约、心跳、步骤和唯一订单任务确保恢复；运行版本变化退出。
- 域名归属、解析、HTTPS 检查通过后启用。品牌素材持久保存，遵循现有商业授权规则。
- 独立测试数据库和站点；仅模拟外部支付网关，不在生产增加跳过验签/标记付款接口。
- 前后端独立功能分支，明确文件提交；每个 checkpoint 合入本地 develop，迁移在本地隔离库验证。
- 不正式上线、不推送共享分支；保留全部无关工作区内容。

## Task 1: 数据与规则基础

扩展流程状态、资格、默认套餐、快照、任务、处理记录、交易、退款和域名表；覆盖新装、升级及新租户初始化。金额按分处理，明确归属和可售条件。
验证：真实 MySQL 新装、旧库升级、自定义前缀和重复迁移；默认套餐保留定价；金额边界和状态/身份验证。

## Task 2: 建单与支付

用户和采购订单快照/服务器金额，库存可选预占，Native QR、支付宝预开窗，纯支付轮询工具；到账核验、重复付款、迟到回调和查单补偿。
验证：订单/回调/查单金额及身份失败测试；二维码内容、轮询不重叠与停止、窗口恢复及既有付款回归。

## Task 3: 租户工作台

资料补充、审核拒绝/通过、按单采购、预占、提交平台、订单详情与进度。
验证：越权、并发预占、重复审核/提交；两条有库存/无库存付款流程。

## Task 4: 平台审批与开通

工作台、退回/拒绝、确认、重试；独立单并发执行器、版本租约、步骤恢复、品牌/管理员/权益/合同、最终消费及激活；续费。
验证：每步中断恢复、唯一租户和授权/额度、续费日期、旧任务运行与升级保护。

## Task 5: 退款与客户交付

原支付主体退款及查询、提醒、我的贴牌、域名归属/解析/HTTPS、经营统计。
验证：退款接受/处理中/未知/失败/重复/多付、冻结释放一次、域名安全和统计逐单核对。

## Task 6: 完整验收

隔离真实后端、三端页面、执行器与模拟支付网关；有库存开通、无库存采购开通、拒绝退款、失败恢复四条浏览器路径。后端套件/语法、三端构建、菜单迁移与产物校验。报告逐项结果，真实扣款退款明确跳过。

## Review Focus

支付主体混淆、缺少金额/交易核验、退款未知结果重试、数据库死锁/并发超卖、旧租约完成、旧版订单行为变化、权益快照读取可变计划、租户数据和凭据泄露、域名 SSRF、交付前激活、运行版本/升级保护遗漏。

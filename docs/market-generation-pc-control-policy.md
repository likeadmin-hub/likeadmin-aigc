# PC 图像与视频创作参数展示方向

状态：2026-10-30 在[批次 18](market-acceptance/batch-18-20261030.md)按用户新增的 LibTV 调研方向收敛共享展示，完成列出的实际页面与回归；早期基线见[批次 13](market-acceptance/batch-13-20261030.md)。本文件不认证模型合同，不扩大资源、SKU、模式或计价能力；不代表每个资源/入口已经完整验收。后续兼容继续遵守本方向，不为了覆盖 API 字段扩张普通表单。

## 用户要求

图像常用输入为生成模式、参考图、提示词、张数、比例、分辨率；视频为生成模式、提示词、分辨率、比例、时长。其他技术性高级参数使用可靠默认值。按当前模型和模式实际能力显示，不给所有型号套同一组枚举，不逐工具逐型号追加分支。

建议补充模型选择，以及视频模式要求的首尾帧、参考图片/视频/音频。可控且明显影响声音结果的生成声音选项按模型显示。生成按钮附近继续显示报价及必要的素材校验提示。

用户随后明确的首尾帧规则：支持首尾帧的模型保留“首尾帧”和“@参考素材”两个 tab；首尾帧区域仅用于首尾帧模式，其他模式选中参考素材 tab；不支持首尾帧的模型不显示首尾帧 tab/槽，仅在有素材能力时显示普通上传框。tab 和生成方式双向联动，第一张上传不能导致模式提前跳走；切模式保留上传并按明确用途转换，最终数量、必填和合同校验仍执行。

## 展示分层

| 层级 | 适用输入 | 展示规则 |
| --- | --- | --- |
| 常规创作 | 模型、生成模式、提示词；图像张数/比例/分辨率，视频比例/分辨率/时长 | 仅展示当前资源、SKU 和模式支持的值；固定单值不占选择控件；缺少独立分辨率声明时不虚构 1K/2K |
| 模式素材 | 参考图、首尾帧、参考视频、驱动音频、遮罩、角色/主体 | 按模式出现，上传后可推断时自动联动；角色和遮罩用业务操作表达，不要求用户填写原生 JSON |
| 有明确创作价值的可选项 | 生成声音、透明背景、质量/速度档位、多镜头 | 仅当前模型/模式支持时出现；声音/档位影响费用时让用户看到含义和新报价；透明背景放在图像用途操作，多镜头放在专用创作模式 |
| 默认隐藏 | seed、采样步数、CFG、采样器、传输编码/压缩、回调地址等 | 采用已确认的声明默认、规格锁定值或明确业务策略；传输/回调由服务端负责；不增加普通用户技术表单 |
| 暂无安全默认的必填输入 | 具体模型/模式额外必填字段 | 提供可理解的业务输入；无法提供时保留该模式未支持状态，不隐藏后冒认完成 |

批次18补充：声音、质量/速度档位、透明背景在共享面板的紧凑选择区直接显示；仅当前适用声明有相应可选字段时出现。固定值显示只读说明，不制造无效选项；与基础清晰度/比例/模式选择重合的字段不重复。可选命名主体默认不显示、不传空对象；旧主体沿用时给摘要和恢复默认，保留原文件。普通创作对已声明且允许 false 的 `multi_shots:boolean` 使用明确的单镜头产品策略，正式默认/锁定和用户显式设置优先；两类请求投影都携带策略值，不将其说成上游默认，不替其他未知必填字段编造值。

负向提示词默认省略，必要时可作为后续专业用途入口，不常驻普通创作。水印、安全审核等按平台与供应商规则执行，不把它们作为本次普通表单可随意关闭的选项。文件/网页链接只在具体素材来源操作出现，不常驻全能参考面板。

固定项必要时显示简短只读说明。例如比例跟随输入图，应显示“跟随首帧”，而不是提供无效比例选择。是否可跟随、裁剪或自行指定，仍须以当前精确市场资源/模式的实际合同为依据。

## 调研证据与适用边界

2026-10-30 用户登录后，另建无生成的测试画布，逐项查看 [LibTV 画布](https://www.liblib.tv/canvas) 当前目录21个图片和32个可选视频选项的基础配置菜单，另4个视频选项在空节点状态禁用，未展开。详见[逐型号记录](market-acceptance/libtv-ui-review-20261030.json)。图片有画质/透明背景或固定4张等差异；视频按型号显示生成声音、生成品质/档位或固定比例、时长，Vidu Q2 Pro另有背景音乐。缺少开关不意味着不支持声音，模式在空素材时禁用也不意味着模型不支持。切换沿用的选中值不是默认值证据；高级弹层和加载素材后的全部模式未穷举。没有上传素材、提交生成或付费。参考其信息层级，本项目参数范围仍使用自己的精确公开声明，不拿其同名模型替代本地合同。

2026-10-30 实际只读浏览了 [ImagineArt 视频创作页](https://www.imagine.art/video/create)：Kling 4.0 的核心为首尾帧/参考素材、提示词、模型、比例、时长、分辨率，另有多段提示词；切换 Seedance 2.5 和 Wan 3 后观察到生成声音开关。不同型号的选项会变化，不是所有模型都显示相同开关。其[图像页](https://www.imagine.art/image)选择 Qwen Image 2.1 后可见比例、Variations 张数及提示词增强等紧凑选项，没有观察到 seed/CFG 技术字段铺在主表单。没有上传文件、输入创作内容、购买或点击生成；不保存账户信息和历史作品。

进一步对照公开官方文档，以下仅用于产品展示设计，**不能替代本项目特定市场资源/渠道/API 版本的完整合同**：

- [Google 图像生成](https://ai.google.dev/gemini-api/docs/image-generation)：比例与图像大小是不同配置维度，支持范围随模型变化。UI 应分别表达，不能把比例字段再次显示为清晰度。
- [OpenAI 图像生成](https://developers.openai.com/api/docs/guides/image-generation)：尺寸、渲染质量、输出格式/压缩和背景是不同概念。透明背景有明确用途；格式/压缩适合默认处理，质量可按产品需要保留易懂的档位。
- [fal Kling 3.0 Standard API](https://fal.ai/models/fal-ai/kling-video/v3/standard/text-to-video/api)：普通提示词与多段提示词互斥，生成声音、时长、比例与 CFG 分别具有不同作用。建议把多镜头做成模式，声音按能力显示，CFG 使用确认默认。
- [阿里云 Wan 2.7 图生视频](https://help.aliyun.com/en/model-studio/image-to-video-general-api-reference)：首帧、首尾帧、续写是不同素材组合；图生比例可跟随输入素材，时长和清晰度影响费用，续写 duration 表示最终视频总长。应按模式标注含义，不能用一个统一“时长”文案掩盖不同语义。

## 共享实现约束

1. 在共享参数声明/投影层增加展示策略，把字段语义、当前模式、公开范围、默认来源及 SKU 关系投影成常规控件和条件素材。首页、创作页、画布、短剧及独立工具复用，不为每个工具追加每个型号的判断。
2. **参数用于请求与参数显示在页面必须分开处理。** 隐藏技术控件不得删除准备器所需的默认值、锁定值、素材或校验；SKU 选择、报价、冻结快照和最终请求使用同一套解析结果。
3. 不按字段名、示例或型号名称猜默认值和能力。默认优先遵守受信任的实际规格、选定模式正式声明和明确业务策略；必填无可靠默认不能静默通过。false/0、未声明与不支持保持区别。
4. 切模型/模式后重算可选范围、素材要求和报价，说明不兼容输入；不静默删除用户素材或更改费用相关选项。历史任务快照不重写；重用历史显式高级值时，不能让隐藏旧值悄悄控制新任务。
5. 张数须与现有批次/单次能力、报价和最终请求一致，不给仅支持单张的上游伪造多图原生能力；页面也不应把图片组数量混同为生成张数。
6. 验证应覆盖实际浏览器上传和模式切换，并检查“页面显示选择 → 上传 DTO → SKU/报价 → 冻结/原生准备”。本地可回滚验证保留退款、幂等与计价，不追加收费生成。

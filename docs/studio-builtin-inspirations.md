# 商品视频、动作同步、剧情带货的跨站点内置灵感模板

1. 租户后台创作记录在“设为模板”后提供“设为内置模板”。仅已完成的视频可使用；商品视频沿用已完成分段作品的适用规则。操作先确认素材可跨站点公开共享，不提交生成、不扣算力。入口受独立后台权限控制，只能设置当前租户的记录和模板，不能通过请求参数指定其他租户。
2. 租户后台的动作同步与剧情带货模板列表支持将普通模板设为内置、更新已有内置；内置项可维护名称、上下架、排序和删除状态。素材及创作参数从原模板更新，租户只能查看和同款。商品视频沿用原有内置编辑机制。
3. JSON 定义位于各应用的 `data/inspirations/`，保存实际素材坐标、编剧快照、文字/结构化脚本、稳定模型资源标识及原生规格。更新交付须包含新增或修改的 JSON 与迁移源码。只在后台保存而未纳入源码交付，不会改变其他独立站点。
4. 图片、动作视频及预览作品引用原公开 OSS/COS/七牛，不把媒体二进制、存储密钥、临时签名、本站文件记录 ID、用户身份、报价或任务 ID 写入源定义。目录须由部署时的 PHP 服务账户安全地拥有写权限；不要开放未经授权的源文件写入。
5. 其他站点安装/更新及首次读取时幂等同步为自己的平台案例，重新映射本地模型 ID，已开通对应应用的租户可同款。模型未同步、未上架或规格不支持时明确提示，不替换为其他模型。普通租户自建模板和历史草稿不被更新覆盖。
6. 删除/下架保留源定义及历史媒体引用，不删除 OSS 对象；保留已分发的 JSON，不用移除文件代替删除操作。共享素材仍占原存储容量，并产生正常访问流量；外部 OSS 清理及过期策略也须保留这些对象。

数据与权限：新增 `app_builtin_inspiration` 为动作同步、剧情带货记录稳定键与版本的映射；三个应用均声明租户后台可调用的 `case/builtinFromJob` 与 `case/builtin`，作用域取自已登录租户身份，平台保留内置内容维护接口。源定义不依赖该映射的原站点数字 ID。现有租户模板不会被自动公开。

验收：`STUDIO_BUILTIN_LOCAL_TEST=x_cn php tests/studio-builtins.php`、商品视频内置模板回归，以及三个应用的安装、普通模板、素材、完整同款和工作流回归。新测试只在本机显式授权数据库内事务回滚，以临时 JSON 目录模拟另一安装的重建，不执行网络、上传或模型调用。前端检查租户入口、平台记录隐藏、跨租户拒绝、取消确认、重复点击和版本提交，并构建平台端、租户端；共享媒体钩子还需验证 PC/移动端构建与既有商品视频行为。

回退：回退对应源码提交，保留业务表、定义及共享物理素材，避免已创建草稿失效。不运行版本打包或发布操作。

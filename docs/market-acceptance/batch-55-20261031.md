# 批次55：存储写入中kill与未完成同键竞争

沿用 `feature/short-drama-next-optimization`。server修改受管本地文件发布和同消费记录的队列创建，补故障夹具、回归及台账；web仍为 `1f52cb5f`，无源码修改。每个feature提交均先合入本地develop再验证，只推server feature。无路由、权限、manifest、数据库结构、价格或正式计量合同变更，收费生成和供应商提交／查询／资产调用均0。

## 本批完成与修复

1. **复现正式地址暴露未完成文件**。生产worker在实际文件写到32字节后被暂停，原本地驱动直接将部分内容写在正式结果URI；这时检查点尚无回执、文件登记为0。kill后重启虽能补完，但写入期间正式地址已是不完整内容。另一个未完成同键竞争场景中，第二worker还会绕过第一名的未完写入提前完成业务结果。
2. **复现已成功文件被迟到打开截断**。第一worker已经通过检查点规划，在打开目标前暂停；第二worker接管租约并完成文件、资产与业务结果。放行第一名后，旧驱动重新以写模式打开同URI，写到32字节被kill，完整文件被截断，但资产和业务仍显示成功，普通再重启也因stored快路径保持错误文件。这不同于批次54“旧下载返回后才进入规划”的窗口。
3. **修复受管本地结果发布**。新增仅供受管稳定目标使用的驱动方法：同目标稳定空锁文件串行化写入，先写同目录隐藏暂存文件，验证大小／SHA256后原子rename到正式URI。部分暂存可重写、完整暂存可直接发布；已经存在且校验正确的正式文件不重写，保留inode／mtime。暂存写入时权限0600，完整输出0644；符号链接、错误大小／来源或非普通目标拒绝。空锁文件保留以防等待者分裂到不同inode；不得在仍有执行者时清理锁文件。数据库事务不跨文件复制或文件锁等待。普通内部上传与云驱动仍走原有路径，没有批量修复旧真实文件。
4. **并发又复现并修复队列缺行插入死锁**。两名执行者接近同时完成后，都SELECT FOR UPDATE同一个不存在的业务回填队列键，再INSERT触发MySQL1213；框架嵌套回滚又报SAVEPOINT trans2不存在，掩盖原异常，造成收尾重试与重启后队列变化。隔离连接器仅记录原始异常、不改变SQL行为，确认错误在 `enqueueProcessResult` 的缺行插入。现在先锁已有消费记录，再读／建对应队列项，串行化同一消费的入队，保留既有优先级、唤醒和租约语义。没有改框架vendor、数据库权限、隔离级别或财务结算逻辑。
5. **8个新生产worker场景通过**。视频与音频各覆盖：写32字节后kill再启动接管；第一名未完成时第二名等待同目标锁，随后第一名完成；第二名已经等待时kill第一名并自动接管；第一名晚于同伴成功才打开存储目标。各场景都等10秒租约自然到期，最终1个结果资产、1份正式文件、1条文件登记、1条业务结果、0份暂存残留、SQL异常0，字节校验正确，业务地址与资产一致，第三次重启保持全部结果／队列行。迟到打开时直接复用成功文件，inode／mtime及业务、资产完整行不变。假账户余额和价格冻结保持。
6. **既有恢复路径继续通过**。图片上传发布后、SQL回执提交前kill的生产worker，以及批次54相同／不同内容的迟到下载两场景均重跑通过；最终1条文件登记，过期收尾事件仍0。11个独立worker场景是8新＋3回归，单独计数，不加进PHPUnit数量。
7. **正常登录页面验证**。新普通画布902、短剧545，各通过正常上传入口添加本批worker导出的一段蓝色视频和一段WAV，2节点／0边／0生成运行。整理布局、保存、关闭、新标签正常HTTP重开后，节点／连线／同一助手关闭状态下的视口相等。两入口实际音视频readyState4、时长1秒，视频32×32、无解码错误；4条上传回执归属匹配、仍用既有tenant／aliyun存储。只操作本批项目，未操作868／510或其他旧项目，未注入身份或读取令牌，积分保持4,372.96。独立worker的私有本地结果再手动正常上传仍是两段验证，不冒认同一HTTP生成任务写回画布或云端受管转存整链。短剧截图在相等性检查后显式适合屏幕并缩放50%。

故障夹具只在子worker注册文件流包装器：打开、写字节、文件锁和rename最终全部作用于私有真实本地文件，暂停点在实际写出32字节后，SIGKILL的是自己启动的生产worker。另一测试专用MySQL连接器仅观察异常，仍使用原MySQL builder／SQL／事务。不是供应商模拟回执执行、原生内核无插桩压力测试、共享多机存储或断电持久性认证。全局InnoDB死锁状态查询被现有PROCESS权限拒绝后，改用上述隔离异常观察；没有扩权。诊断连接器初轮builder名称修正属于夹具修正，不算产品故障。

# 批次26：三种PC入口共享档位、参数及验收证据汇总

本批完成首页、现代创作页、独立视频旧页对共享业务档位的接入，并完成其代表性真实页面上传/切换/替换/删除/估价。**整体适配仍未全部完成；没有追加收费生成。**

## 具体修复

- 三入口从 `generationVariantOptions` 读取档位值和标签；移除首页固定pro/fast/standard白名单、现代页固定Grok选项，以及三处按Grok原生型号匹配档位的逻辑。`generationVariantValue` 解析既有代码/标签及声明默认；`generationVariantMatches`、`generationPreferredSku` 绑定精确在售SKU，不凭型号名称猜能力。
- 当前业务档位、素材生成方式和分辨率进入共享参数元数据。菜单按档位SKU约束分辨率、比例、时长和素材方式；先确认有效分辨率再取时长，保留仍合法的选择。页面展示、参数默认、报价及提交准备采用相同有效业务输入；现代页的最终SKU回填也取消Grok特例。
- 实际交叉验证复现了 `720p` 与 `720P` 大小写不同会让首页/现代页回到480P，选到不同SKU与价格。现在三入口保留等价历史分辨率，并按声明默认调整真正失效的值；调整信息显示业务档位和当前参数。
- 实际首页复现默认 `5s` 与菜单 `5秒` 比较失败，滑块停在0，增加一步会跳到2秒。共享设置按数值定位；父页同时规范合法时长标签，现代页5秒菜单也恢复选中标记。没有改变实际时长或计价公式。
- 独立页在素材兼容性恢复时重新投影选择；暂时无匹配规格时保留原档位/参数，删图报价失效，重传后恢复对应选择。提示使用共享业务标签。

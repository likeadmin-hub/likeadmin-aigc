# 批次37：必填素材方案、旧请求冻结与同步分类边界

本批按最新用户决定收口：**不实施“常规视频／视频工具”的前端分类、后台分类维护或新增入口**。用户将自行在API平台调整模型分类；本地只补上游模型价格同步的分类边界。此前已经完成的两类画布必填素材方案选择修复保留。没有执行实际上游价格同步、市场上下架／配置修改、收费生成、重试或供应商任务／资产调用。

## 模型价格同步

原同步已只查询 `text/image/video`，但其他类型若仍出现在返回中，会经通用兼容规则兜底为text。新增同步专用的严格判断，覆盖目录收集、完整工厂定价和商品写入三个边界：

- 明确属于其他分类的模型不创建或更新为本地文本／图片／视频商品，不使用型号黑名单。
- 定价响应的明确分类优先于旧缓存分类；缺少分类的旧响应保留已知请求类型，完全缺失或格式错误则跳过。
- 过滤后空目录继续走既有空目录核验，保留价格同步部分失败／暂时空目录保护。没有执行无条件清理或修改旧任务快照。
- 仅模型API受本次限制，应用API分类逻辑不变。上游依据是类型编码，单改显示名称而仍为video不会被排除。已有本地条目需在后续实际同步确认变更后才可能退出，不能声称本批已下架。

[同步边界证据](unsupported-model-categories-batch-37-20261031.json)为纯本地合同检查：audio、video_tool、motion_control、other、embedding等合成分类的工厂定价为空，商品写入在访问数据库前返回null；验证三类支持值、旧响应上下文、缓存冲突和异常类型。不需要新增接口、权限、manifest或数据库迁移。没有调用真实同步来修改价格。

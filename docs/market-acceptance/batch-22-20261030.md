# 批次22：实际PC上传、替换与引用绑定

本批修复两项实际页面问题，并补首页、现代生图/视频页的正常上传和估价证据。**整体模型/应用适配仍未全部完成，没有新增收费生成。**

## 页面复现与共享修复

1. 全能视频应用正常上传两张合成图后，提示词有两个图片引用。替换第二张图片成功时，素材仍在、估价200，但提示词里的 `@图片2` 被删除。这是页面实际复现，不能由此前本地准备通过掩盖。原因是上传中的素材暂时退出可引用列表，原观察器按“已删除”重排提示词。
2. 新共享 `useReferenceMentionRemapping` 由创作页图片/视频共用的Studio与首页Composer一起使用。它保留最近完成上传时的引用身份，等待整个上传/失败恢复事务结束，再按实际保留的使用ID重排。待上传素材仍不能作为新的可用引用，上传校验、报价失效及生成拦截继续生效；真正移除素材仍删除对应标记并重排剩余序号。失败上传移除后异步恢复旧素材期间也不提前删提示词。没有按型号新增分支，也没有修改后端合同。
3. 生图页批量上传期间，主表单的移除和添加按钮原来仍可点，展开编辑与视频区则已有保护。本批统一忙碌状态，并在首页/创作页的移除处理器检查上传/提交状态，防止后台恢复与交互移除互相覆盖。最终实际页面观察到上传中所有移除、添加和生成控件禁用；上传完成后操作恢复。

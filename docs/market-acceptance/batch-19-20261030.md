# 批次 19：画布图片维度、档位选择及声明型素材计数

本批继续全局共享适配及实际页面回归。列出的修复和有限验收已完成，**全部模型/应用与工具兼容仍未完成**，没有新增供应商生成或收费请求。

## 修复及合同边界

1. 普通画布原先丢弃清晰度为空的 SKU 分组，导致只提供比例的 4o、Kontext 没有比例控件；同一比例先取一条 SKU 又丢失 Pro/Max 等价差方案。现在共享 `generationImageQualityGroups` 保留无独立清晰度的组、每条真实 SKU 及零价，再交共享模式/价格选择。未声明独立分辨率不补造一个，仍按当前模型、模式及 SKU 限制选值。
2. 画布不再将首条 SKU 锁定值提升为全模型锁定值；档位重置、删除上传参考图及连线素材改变时重新选取适用 SKU。以当前 patch 和节点为准，避免删除后还读取旧参考图，也不把连线引用复制进上传列表。清除旧清晰度/比例别名不再把不可用值重新带回。没有增加逐工具型号分支。
3. 共享面板的当前有效默认选项与“恢复默认设置”分开显示。真实显式 SKU 仍采用自身锁定值；不能为了重置画布的派生 SKU 而全局将显式 SKU 默认改成最便宜规格。初轮此类改法被已有守卫捕获，最终实现保留显式选择语义。展示默认值本身不修改保存参数。
4. 实际准备中发现 4o 两张图已在原生 `files_url` 保留，但原通用媒体提取只靠字段名，计量上下文为 0。新图片快照记录内部 `media_meter_revision=1`，共享提取器可按**选中的冻结素材声明**识别明确类型的顶层字段；既不全局认定 file 字段都是图片，也不凭 URL 后缀/浏览器提示猜类型。不明、冲突及嵌套结构不在本批补认。图片附加计费仍无法完整计数时拒绝报价，防止按 0 张继续。
5. 无此计量版本的历史快照沿用旧提取及价格语义，单测比较旧上下文、旧价格及快照不变；不回写历史任务、补扣或改已有账单。现有计价公式、预占/退款/幂等流程不改。视频和应用没有自动迁移到新版本，不外推本修复覆盖所有结构。新增字段属于服务端内部冻结快照，无新业务 API、迁移、权限、能力来源或市场配置变化。

# 批次 01：目录基线、公开素材模式与已选 SKU 保留

## 本批结果

两个可复现的共享缺陷已修复。`AigcImageChannelService::sanitizeChannels()` 会移除比例行的私有 `provider_params_json`，前端原有模式过滤继续读取该字段，因此不能依据实际公开配置区分文生图和参考图对应 SKU。现在从比例行精确关联的 `model.skus[].locked_params.generation_type` 读取模式，兼容旧形状但优先使用正式 SKU 锁定参数，不修改目录。

后端原来的通道选择只按清晰度、比例与变体取第一行；多个 SKU 的维度相同时，会覆盖用户指定规格。现在在当前受信任通道的相同维度中优先匹配请求 SKU，保留所选价格和后续锁定参数。维度变化仍重新协商，未知选项与后续模型能力、SKU、计量校验继续生效。未加入按模型名称分支，未改变模型能力来源、数据库、权限、路由、任务状态或后台能力面板。

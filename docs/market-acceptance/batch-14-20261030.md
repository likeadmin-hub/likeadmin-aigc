# 批次 14：短剧画布复用共享精简设置与请求投影

本批修复短剧画布与创作页在参数处理上的实际差异；**整体模型/API 兼容仍未完成**。证据见 [逐场景记录](short-drama-controls-batch-14-20261030.json)。没有把有限组件观察、离线构造或测试数量当作整页/全量 SKU 验收。

## 已修复

- 原短剧 `runPayload` 丢弃已保存的高级选择，改用声明默认，并为没有默认的必填枚举/布尔值任意填第一项/false；它还无条件发出 generate_audio=true。现在与首页、创作页共用标量校验和定价默认解析，保留模型范围内的显式 false/0，缺少可靠默认时省略，由合同拒绝缺失输入。
- 短剧图片/视频节点复用既有精简“生成设置”：只显示声明支持的创作选项、必填无可靠默认项，以及旧显式技术值的可见摘要/重置。未出现新的一长列 API 技术参数；无创作选项且无旧值的 FLUX 不出现额外设置。
- 旧 generateAudio 仅在它确为布尔值、模型声明了对应布尔声音输入时在内存兼容；模型范围内新值优先。编辑或重置后移除旧开关，避免恢复默认后旧 false 再出现。没有改写数据库中的历史画布。
- 新共享 `generationControlPayload` 复用 `generationParameterPayload` 的解析核心，为只允许 advanced_params 的业务边界传递可靠定价默认；不转发原始 provider_params、素材 JSON 或身份/计费覆盖。既有首页/创作页/独立画布请求形状保持。
- 短剧后端保留显式 material_mode 到共享准入与报价签名，仍由当前模型、模式、素材、SKU 和原生校验决定能否受理；拒绝非字符串模式，不放开原始供应商参数。
- 设置按钮适配画布工具栏宽度和既有基础选项顺序，弹层使用画布自身明暗模式变量；没有改全站主题。

# 批次25：共享应用档位、短剧/画布和复杂素材边界

本批关闭短剧丢失应用档位、节点隐藏业务档位及跨档位参数联动问题，补最大组合素材的有限交叉。**整体适配仍未全部完成；没有新增收费生成。**

## 复现和共享实现

1. 实际生产投影/本地准备复现：Grok应用108的标准参考图480P、1:1、5秒，在普通画布为标准SKU140/76.7，短剧前端请求不带mode、后端受限投影也丢mode，变为快速SKU137/148.83。现在两层都保留明确业务档位，共享市场准入继续检查SKU、素材、时长及计价，不接收客户端价格、原生provider参数或SKU覆盖。
2. 共享目录增加 `generation_variants: [{value, market_sku_ids}]`，由同一注册档位身份和当前在售SKU生成。共享前端参数模块按此绑定投影选项和时长/分辨率、限制偏好SKU；画布删去逐型号档位匹配及固定pro/fast/standard白名单。短剧从相同声明产生mode选项、默认与请求。它是计费档位投影，**不是新原生合同或模型能力认证**；后台能力来源没有变化，平台/租户源码不涉及。
3. 隔离实际节点验证发现两种节点曾统一隐藏mode，后台准备修复不会自动让用户能选。现在只显示当前模型确实声明的业务档位，技术mode仍沿用共享默认/必填面板；“生成档位”与素材生成方式区分。没有给每个工具添加型号分支。
4. 使用没有已知型号名称的合成 `rapid/steady` 声明验证可复用性，并复现短剧切档位使分辨率720→1080后丢掉时长选项、请求duration变0。现在先解析本次有效分辨率，再约束时长；原选择5秒保留。普通画布也按同样次序投影。修复短剧可用选项误带“当前市场模型不可用”提示，保留真实禁用理由。

- 后端仅对已声明 file/link 素材模式、具有 string URI 或 array-string URI 类型的字段提供 file/link 控件 metadata；未声明或结构不透明的字段不猜测。共享素材校验拒绝无主机、凭证 URL、相对地址及空地址，不下载文件或网页。

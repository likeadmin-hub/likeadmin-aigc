# 批次27：查询重载稳定性与短剧分镜工作台共享档位

本批修复带型号查询重载时的参数竞争，并将短剧分镜工作台单条与批量的档位、规格及SKU选择接入共享声明。工作跨10月30日至31日完成；整体市场适配仍未全部完成，没有收费生成。

## 已完成的修复

- 现代创建页原先并行加载图片/视频目录，两者都会写当前编辑器参数；视频目录还会先应用默认型号，再应用URL指定型号。[历史源码重放](catalogue-reload-before-batch-27-20261031.json)确认两种响应顺序都可把图片的1K/3:2/4张带入视频，最终参数依响应顺序变化。该重放使用模拟目录与setter，不是浏览器网络证据。
- 现在目录按媒体分别就绪，非当前媒体只缓存；先精确解析URL型号，再应用该型号声明默认及有效参数。旧响应不能覆盖新目录；未就绪或请求型号不可用时阻断报价和生成，精确市场ID不再模糊命中较短ID。图片/视频两种入口、两种完成顺序、旧响应、精确ID及报价门禁有真实源码回归。
- 分镜工作台原模型归一化丢掉 `generation_variants` 等共享字段，并保留独立Grok档位/原生型号分支。现在保留公开声明，复用共享档位标签、默认、SKU绑定与可选值；先确定档位和分辨率，再确定时长，保留仍合法的选择；实际素材方式参与精确SKU选择，无匹配规格时交既有准入明确拒绝。未用型号名称推测能力。
- 单条与批量的型号变化采用同一规范化规则；无效时长使用声明默认，批量档位调整后的分辨率回写到单条设置。提示随型号/手动设置更新，不残留旧型号4K。页面验证发现我新增提示样式放在Sass `@use` 前，已修正，并追加实际样式编译守卫。
- 后端只在短剧市场选择边界把已有 `video_mode` 映射为市场业务 `mode`；工具动作 `video_generate` 保留在调用侧。嵌套/顶层优先、缺省/显式空值、未来档位及0/false均有边界验证。不改路由、权限、迁移、能力来源、供应商配置或计价公式；既有字段契约无需新增接口或版本发布。

# 批次 10：公开素材要求与 Wan 原生方案 SKU

本批给共享素材面板补上当前模式的“素材要求”，并修复同一个 UI 生成方式对应多种原生方案时的 SKU 选择。没有给 Wan 或某个工具增加型号分支。

## 共享变化

共享素材面板只读取当前公开模式已有的规则，不从型号名称猜限制。已知字段名替换为该字段的中文标签，相同提示去重；传输/内部模式注释过滤。没有规则就不显示此区块，不把缺失声明当作不支持。以折叠区展示，不改变参数、上传或请求值。Grok 关键帧的正值、间隔、必填参考图等既有规则已进入这条共享投影，但本批页面连接中断，尚未实测展开。

Wan 2.7 的续写与参考两种原生方案都对应 UI“全能参考”。实际前端组合发现，参考方案的 32 项请求先选了续写 SKU 690/691，再由后端纠正。共享选择器现在先按当前素材方案的原生模式匹配已公布的 SKU 锁定值，再处理视频输入分档、默认值、用户设置和明确 SKU。缺少对应候选时不回退到另一个原生模式的价格；无原生模式声明的旧路径保持原筛选。

后端素材、类型、数量、模式、SKU、计量、幂等和退款保护保留。后台能力来源、原生合同、路由、迁移、权限和价格公式均未修改；本批后端业务源码没有变化。

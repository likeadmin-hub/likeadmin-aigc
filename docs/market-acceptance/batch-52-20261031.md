# 批次52：转存检查点、中断恢复、有效音视频与短剧上传竞态

分支沿用 `feature/short-drama-next-optimization`。server 范围为共享结果文件检查点、资产终态保护、图片／视频／音频服务内部适配、隔离测试和台账；web 范围为短剧上传迟到回写和视口恢复。每个feature提交先合入本地develop后执行验证，只推两仓库的任务feature。远端develop继续按已有决定暂缓合并，没有发布或收费生成。

## 本批完成及修复

1. **补齐文件已写入、回执未提交的恢复**。新共享 `AiTaskManagedFileService` 在现有资产 `storage_meta` 中先写入版本1检查点，冻结源地址指纹、目标路径、字节校验和、大小及存储范围／引擎／域名。路径按租户、用户、资产及内容校验和稳定生成，存储I/O不持有数据库事务。文件登记与上传回执在短事务内通过资产锁串行保存。本地恢复先核对文件大小、SHA256、归属和存储信息，完整文件可补回回执而不重写；部分文件不当作成功，可向同一目标重新保存。来源、内容、存储或文件归属变化明确拒绝，保留核对。
2. **三类转存共用检查点**。图片／视频／音频服务在原有参数后增加仅内部使用的可选资产ID；既有非队列调用保留其存储路径。新增任务转存检查实际MIME／允许类型与扩展名，补AAC和M4V实际MIME别名；不信任仅声明的文件类型。云存储仅有计划路径时不视为上传完成，已有持久文件回执才允许恢复；本批未实际执行云端结果转存。
3. **修复已存资产被迟到异常降级**。合成worker在上传完成、资产已标stored后注入业务摘要回填异常，修复前资产被catch改回retrying。现在仅更新尚未stored的失败资产；回填或排队异常仍让作业重试，但不重新打开已完成的上传。没有批量改真实旧资产。
4. **实际进程中断及后续异常恢复通过**。随机空表前缀、私有文件／缓存／临时目录运行生产 `AiTaskWorker`。在实际文件上传后、文件回执事务提交前暂停自己子进程并SIGKILL；第二进程等待自然租约到期，复用完整本地PNG，修复回执并继续业务回填。再注入上述迟到异常，确认作业重试时资产仍stored，最终图片业务结果使用受管URI；第三进程重复启动保持幂等。领取共3次，最终1个结果资产／1个文件登记，原文件mtime不变。无供应商调用或真实钱包变更；随机表、私有根和本批子进程均已清理，原常驻服务未重启。
5. **真实有效媒体文件存储通过**。用本地ffmpeg生成无隐私色块／静音样本，经实际生产资源服务、内嵌结果入口和本地存储驱动验证MP4、WebM、MOV、M4V，以及MP3、WAV、OGG、FLAC、AAC、M4A、Opus共11种容器实例，字节和文件归属保持。三类文件的回执前／后中断状态恢复、无效字节拒绝、来源／内容／归属／存储变化及部分文件恢复均覆盖。这不是视频／音频完整业务worker或所有损坏流的认证。
6. **修复真实短剧批量上传丢地址**。正常登录项目534中，批量上传和整理画布并行后，音频／图片节点未保存最终地址，视频正常。实际原因是保存冲突安装合并文档后替换了节点对象，上传闭包还写旧对象。现每个异步步骤后按原项目范围和节点ID定位当前节点；删除节点或切换租户／用户／页面后不迟到回写或复活节点。已有布局及其他元数据保持，blob在完成清理时撤销。534已命名“修复前复现”并保留，不伪称修复前通过。
7. **修复短剧视口重复重开平移**。保存绝对坐标而不保存画布尺寸，会在重开后恢复助手面板宽度时继续平移；实际观察一次累积194px，节点和缩放未变。视口JSON增加可选 `stage_width`／`stage_height`，按相对中心恢复，支持初次测量前尺寸为0的顺序；旧坐标仍按原语义读取。实际正常HTTP重载、恢复相同面板状态后，节点、边和完整新视口均相同，5项有限恢复检查通过。截图之后显式使用适合屏幕，不混入相等性对照。

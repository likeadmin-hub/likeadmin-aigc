# 批次 07：真实混合上传与主体结构素材

## 本批交付

PC 上实际上传本地合成图片、6 秒纯色视频和 6 秒纯音，H3 自动切全能参考，768P、生成 5 秒时估价 352。切 Kling 并将上传素材选入主体后，原先出现“当前生成方式不支持已添加的素材角色”：后台仅用普通媒体字段匹配上传的类型，无法识别主体中的已声明 URI 子槽。

共享素材校验现在要求显式分组字段、实际原生结构、正式声明 URI 子槽及原上传地址一致。仍执行类型、必填、数量、模式、素材保留与 SKU 校验；文本名称/描述或形似图片的普通文本字段不能冒充媒体。完整未知结构没有被自动认证。

主体的 `element_input_urls` 可以容纳图片或视频。共享计量先从安全下载的内容确认类型，图片读图像信息，视频复用既有 ffprobe 测量；不根据客户端类型、后缀或时长提示猜费用。视频输入 SKU 分档和参考附加计量使用这些事实。重复原生编码槽按槽保留；历史冻结上下文仍按原快照计算。Kling 当前视频输入规格按输出秒数分档，H3 按输出秒数加参考视频秒数计量；不能将同一个公式套给所有模型。

前端又发现无视频主体组合仍先取“含视频”SKU，后端重新选择无视频规格。共享 SKU 偏好已根据公开的视频输入锁定值过滤候选，再处理默认与用户参数，6 项差异已关闭。主体图片/视频、音频和起止时间补中文标签；字段定义没有明确单位时不自行标秒或毫秒。没有改能力来源，本批不调整后台能力面板。

# 批次 06：视频音频定价默认与旧原生时长校验

## 已复现的问题与共享修复

视频表单先取当前维度的第一条 SKU，再通过该 SKU 的锁定参数投影高级字段。Kling 3.0 Omni 文生模式正式声明 audio=false，目录第一条是有声规格，页面却显示“模型默认：开启”。批次 04 只检查过未绑定页面派生 SKU 的请求，未覆盖这次实际 UI 反馈。

本批将图像同维度 SKU 偏好抽成 `generationPreferredSku`，供图像比例和视频首页/创作页共用。调用者继续筛选分辨率、时长和素材模式，公共函数按声明默认或用户参数匹配其中的定价变体，兼容的明确 SKU 可保留。它不改原目录/价格，不增加型号分支。没有默认声明的模式不会被本批记录为已证明存在某个 API 默认值。

负向检查还复现：已有本地原生合同的旧模型，时长规范化只对新版 reviewed 合同检查原始整数类型/智能值。H3 的 4.5 会先被截成整数，-2 会回落成可用时长。现在旧原生合同也在规范化及预占替换原时长之前执行相应校验。合法整数叙事时长仍按原规则协商；H3 3→4、16→15 秒不是错误输入通过，单列为已验证的预期行为。锁定时长和正式声明的智能时长由现有回归保护。

这是对已有合同的约束执行修复，没有编造完整合同，没有扩大对缺失合同资源的能力认证。后台能力来源未变，因此本批不改能力面板。

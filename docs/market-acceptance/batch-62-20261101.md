# 批次62：专用剪辑统一结果与无人轮询恢复

分支 `feature/short-drama-next-optimization`。server负责原生剪辑关联、持久结果作业、共享受管资产／只读结果和终态结算；web负责PC剪辑共享状态、受管视频与历史轮询。现有响应增加可选 `generation_task`，原生 `task_id` 含义、版本1结构及原生账务保留；无新API路径、DDL、菜单、权限或manifest版本。沿用授权暂缓合并远端develop，源码只推匹配feature。

## 完成及实现

- 新剪辑在供应商提交前，原生任务、统一任务及 `native_smart_clip` 作业同事务持久化；worker只查询已有供应商ID，不提交生成。worker启动／周期发现和现有reconcile补投可关联已有受理任务；未安装剪辑应用不进行扫描。
- 上游查询与文件保存分开。剪辑结果直接复用既有受管视频转存、稳定路径、检查点和自然租约恢复；原生结果、原生扣费、统一完成状态在原任务锁下完成，不另造消费或重复扣费。
- 统一读接口返回真实受管资产ID、存储归属、媒体信息和账务状态；只读查询不联系上游。跨租户／用户、已删任务、已删结果与不匹配资产均不暴露；混合任务批读保持请求顺序。原任务中心保留原生剪辑行，排除新增统一行的重复统计。
- PC结果展示／下载采用统一就绪视频；历史打开自动恢复待完成轮询，临时HTTP失败保留已受理任务，卸载后的迟到响应不重开定时器。旧未关联历史保留原兼容路径，表单及三种生成模式保持。
- 修复作品单独软删会写不存在的更新时间列的问题；不引入表字段或改写原作品。

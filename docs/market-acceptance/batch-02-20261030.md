# 批次 02：必填 size 比例、图片分组与遮罩

## 共享修复

上批失败的 `生成4o图像` 精确身份为 model `official-33-147ffdea964655ab26` / channel `official`，产品 281 / SKU 390。已有本地原生合同的 `size` 必填且枚举为 `1:1`、`3:2`、`2:3`。目录比例投影及请求转换原来只识别 `image_size`；前端找不到对应比例，估价没有提供 `size`。此前高级面板虽可手工设置此字段，基本比例与默认估价仍不完整。

本批在公共投影和请求准备层识别 `size` 的比例枚举，PC 首页/创作页共用同一控件函数；后端其他共享准备消费者也收到相同的 ratio → size 转换。基础比例拥有该字段时，高级面板与旧高级参数不再成为第二个来源。保留空分辨率组承载报价和比例，但不虚构 1K/2K 等清晰度。实际像素尺寸、命名预设与独立渲染质量仍按其声明区分。未知枚举、缺少必填值、分辨率冲突、SKU、素材与计量校验未放宽。

源码：server `c94f4957a`，web `726ae97a`。没有型号名称判断或逐工具特例，没有修改模型能力来源，因此本批不调整后台能力表。

# 批次 05：只含比例的模型、版本 SKU 与尺寸所有权

## 实际问题与共享修复

PC 复现了“生成或编辑图像”声明 6 个 aspect_ratio、页面却没有比例控件的问题。模型没有输出清晰度定义，页面共享过滤器把空清晰度分组丢弃，连其中的比例/定价行也一起丢了。现在对未声明输出清晰度的模型保留空分组以承载有效比例，基础清晰度控件仍隐藏，不能虚构 1K/2K。它同样适用于明确 aspect_ratio 的其他模型，不按型号判断。

恢复比例还需要正确选择同一比例下的不同 SKU。此前去重只取第一行，可能从默认 Pro 变成排在前面的 Max。共享比例投影现在在当前素材模式、相同基础维度的候选中，以可编辑定价字段的公开默认值或用户值优先匹配；兼容的明确 SKU 继续保留，用户改变定价参数仍能协商到另一规格。原始目录、价格、模式与材料校验不被改写。对整个基础尺寸组都固定的值不应用其他尺寸默认偏好。

修改只在 web 公共 `generationParameters.ts` 与回归，源码 `852cc15e`。PC 首页与创作页共用此投影，不为各工具/型号增加分支。后端业务 API、能力来源、数据库、账单、历史任务和计价公式未改；本批不调整后台能力面板。

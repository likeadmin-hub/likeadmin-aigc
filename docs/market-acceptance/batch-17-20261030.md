# 批次 17：独立旧页共享必填设置、可靠默认与 HTTP 标量保留

用户本批优先项已实施：独立生图 `/app/aigc_image` 和视频 `/app/aigc_video` 接入共享必填参数、默认设置和素材面板，并进行受影响入口回归。**整体模型适配仍未全部完成，未追加收费生成。**

逐资源有限证据见 [16 个旧页场景及实际页面观察](standalone-controls-batch-17-20261030.json)，不得据此把完整验收单元改绿。租户 1 当前只读旧页目录为图片 56、视频 65 个选项；未做市场同步或修改上架配置。

## 实现和复现

1. 两个旧页的前端渠道转换原先删除了参数合同和素材模式；现在保留公开目录声明，复用 GenerationParameterPanel、GenerationMaterialPanel 和 useGenerationControls。必填无可靠默认保持显式输入并阻止估价；不猜第一枚举或 false，显式 false/0、旧值摘要、恢复默认及模型作用域沿用共享规则。
2. 图像按当前素材模式和档位选择比例对应 SKU；视频复用共享 SKU 偏好选择器，并以最终所选市场 SKU 校验规格。实际复现：Kling 3.0 没有独立分辨率组，补齐镜头模式后仍被旧规格表误拦截；修复后按选定 SKU 处理。没有分辨率维度时不强制选择或制造“undefined”清晰度。
3. 报价和最终单任务提交复用同一构造函数；图片批次数量仍按既有逐任务流程处理。参数、模式、素材及业务输入变化立即使旧报价失效，250ms 合并估价更新，迟到响应不能恢复旧报价的可提交状态。素材赋予独立使用 ID，blob 仅用于预览。
4. 实际浏览器发现 HTTP 层把 JSON false 经全局 trim 变成空字符串，Kling 单镜头返回“多镜头格式或范围不正确”；同一 DTO 直接调用服务却成功。共享 Request 过滤现仅 trim 字符串，保留布尔值、零、浮点数和 null。GET/POST 默认过滤均保留类型；字符串裁剪、显式指定过滤器和未经滤原始读取保持既有规则。该修复适用于共享 HTTP 输入，不给各型号或工具添加例外。HTTP 类型保留是本批新增的行为边界，合同、素材、SKU 和计量校验仍执行。
5. 不新增 API、迁移、权限、manifest 字段、供应商协议、能力来源或计价公式；后台能力表不涉及，按用户要求不调整。旧页现有常规布局、风格/反向描述和历史展示未重设计，不把本批称为所有旧页展示策略的全量核验。

## 实际浏览器与有限准备

- 独立生图：Ideogram V3 默认均衡 28 → 极速 14 → 恢复默认 28；Kontext 对应的“生成或编辑图像”默认 Pro 20 → Max 40，无独立清晰度仍可报价；Nano Banana 2 Official 三张无隐私合成参考图正常上传，4K、1:1、1 张报价 48.64。
- 独立视频：Kling 3.0 缺镜头模式明确阻止；选择单镜头，4K、关闭声音、3 秒报价 798，切标准档为 168。全能视频应用实际上传两图+视频+音频，4K、1:1、5 秒自动全能参考报价 200。
- 现代视频创作页交叉复核：Kling 3.0 文生视频、标准、关闭声音、单镜头、3 秒，同样报价 168；保留首尾帧/参考素材 tab 既有规则。切模型保留的图生模式需切成文本模式，无图时正确阻止。
- 本批未抓浏览器 wire DTO。另以实际旧页 setup、SKU 选择和构造函数，从可见选择及已授权合成文件存储 URI 重建请求，经真实 app Request 默认过滤 → 本地估价 → 共享准备/冻结检查。16 个有限场景中 15 个通过、1 个缺必填预期拒绝，逐项身份/SKU/模式/维度记录在 JSON；覆盖 Kontext Pro/Max、Ideogram 两档、Nano 2K/4K 三图、Kling 声音/档位、Wan 显式声音、全能应用组合/首尾帧/三帧/三参考图。
- 15 项通过核对报价 SKU/金额、原生素材数量、序列化冻结后原生输入和计量上下文。视频另比较正式开放平台准入准备；未创建任务。准备器自带持久 URI 规范化和素材保留校验，不能额外拿相对 URI 与公开 URL 直接比较而误报丢失。
- 浏览器进入旧页前只读确认租户 1 两类任务均无可刷新 running+provider_task_id 记录，未触发历史任务轮询更新。仅通过本地 SaaS 正常上传本批合成素材；无供应商资产接口、生成、预占或扣费。
- 本机仅表单证据：`/tmp/market-batch17-standalone-video-uploads.jpg`（两图/视频/音频）和 `/tmp/market-batch17-standalone-video-mixed.jpg`（所选规格及 200 报价）。不提交素材、截图或构建产物。

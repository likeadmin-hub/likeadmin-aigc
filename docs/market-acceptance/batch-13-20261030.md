# 批次 13：模型和模式驱动的精简 PC 表单

用户要求优先完成的精简表单已实现，并完成下列代表性实际页面验证。该结论仅指这项共享表单调整，**不表示全部模型/API、SKU、复杂素材及入口已完成兼容验收**。

## 展示与请求边界

- 图像保留模型、生成方式、提示词、张数、比例、分辨率；生成方式随参考图和当前模型联动。视频保留模型、生成方式、提示词及实际支持的比例、分辨率、时长。单一取值显示固定规格，不再提供无意义的选择框；未声明的独立清晰度不虚构。
- 共享生成设置只保留声明支持的声音、质量/速度/档位、背景等少量创作选项。其他可省略参数不在普通表单铺开，也不填入猜测值。声明锁定值、可靠默认、原有请求准备和全部校验保留。
- 必填且没有可靠默认的输入仍显示，并提示“需补充设置”。本次有限目录观察涉及 Volcengine 对口型的 mode、Kling 3.0 的 multi_shots、Kling-2.6 motion-control 的 character_orientation；不自动选择第一项或替用户填 false。镜头模式和人物朝向参考改用业务标签。字段默认值必须通过已有类型/范围校验；false/0 保留，不把 example 当默认。
- 旧自定义参数不会静默丢失或暗中沿用：有可见摘要及恢复默认操作，清除只作用于当前模型的这些设置，不重写历史任务快照。已声明的可选主体、关键帧和文件/网页来源通过“添加”操作展开；必填和已有值继续可见。
- 比较了精简前后共享参数投影：当前 121 个公开资源的 777 个有限型号/渠道/SKU/模式上下文中，默认参数请求逐字节一致；1,232 项显式参数观察保持原值。它们仅是展示和投影观察，不证明这些 SKU/模式组合均已受理或生成成功。

## 首尾帧与参考素材：按用户最终规则

支持 start_end 的模型保留“首尾帧”和“@参考素材”两个 tab。仅首尾帧模式显示两个帧槽；切换任何其他模式时选中参考素材 tab。不支持首尾帧的模型不显示首尾帧 tab/帧槽，使用参考素材上传框；没有素材能力时不虚构上传能力。

tab 与生成方式双向同步。首尾帧模式上传首张后仍停留在该模式，以便补尾帧；缺帧的终态校验仍拒绝。显式切换模式时共享层调整图片用途，保留上传、顺序、地址和使用槽；外来显式字段绑定不强行改写。首页紧凑生成器与创作页共用同一逻辑，最终报价/提交继续使用既有规范化及合同校验。

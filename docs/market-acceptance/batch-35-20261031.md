## 正常登录 HTTP 验证

[正常 HTTP 与持久化证据](authenticated-grouped-projects-batch-35-20261031.json)记录两个新隔离项目。普通画布经产品既有剪贴板导入添加合成业务节点；短剧从空白视频节点实际编辑，使用已有合成文件。没有用 SQL 写入代替 HTTP 保存。

- 普通画布：Kling 3.0，两主体各2图，同字段共享红、绿图，4个独立用途。原版本删除其中一个用途后仍保留4个结构引用却未标歧义；[历史复现](grouped-http-before-batch-35-20261031.json)保留旧版本。修复后删除及再次协调会保存字段／URI 歧义。重开后修复表单和生成门禁保持；明确移除第一主体后，保留第二主体和2个引用，恢复4K／有声／5秒／16:9，页面预估1330积分。
- 短剧：从空白创建两主体，同一合成文件从素材库选两次，保存2个独立用途。SQL读回及首次重开节点完全一致。删除一个用途后，标记真实保存；重开仍显示歧义并禁用生成。明确保留一个主体后恢复报价；最终源码又补了一轮同文件添加／删除、歧义重开、移除旧结构引用及重新选择图片，恢复1主体／1用途和1330积分预估。
- 两项目最终均为1个生成节点、0条连线、0条运行记录。只调用非收费报价，没有点击生成。页面预估没有捕获网络请求 DTO 或 SKU，不以页面显示值反推 SKU；与下文只读准备证据分别计数。
- 短剧本地素材库跨隔离画布复用通过既有登记接口在当前画布建立本地记录，再绑定返回的素材身份。相同文件的多个用途共用本地资产身份，但保留各自用途槽位；原画布素材记录保持。没有放宽后端租户／用户／画布校验。

最终短剧新标签页中的歧义提示、禁用状态及恢复报价均实际观察；该页控制台错误和警告为空。验证中调整过视野与缩放；普通画布多出的空白测试节点已经通过正常页面移除。节点编辑操作及视野数据只影响上述隔离项目。

## 修复的共享边界

1. 普通画布属性和短剧可主动展开已声明主体、角色分组，从空草稿编辑，不再只能在有歧义时修复。控件 ID 按组件实例隔离。结构选择的用途写回目标节点，不修改来源文件或连线。
2. 本地参考数组覆盖前先比较旧用途。只移除同字段共享文件的一份用途时，保留其他用途并标记歧义；全部移除时清空相应结构 URI，保留行供必填校验。显式重选新素材能够恢复空组，仅改名称不会解除标记。
3. 分组值按型号保存，因此该型号其他素材方式若声明同一字段，也必须继承该字段的未解决歧义；未声明该字段的方式及其他型号不受影响。明确修复／恢复默认同步清除该型号各方式中对应字段的标记，其他字段保持。此处纠正批次34“其他方式不受影响”的过宽表述。
4. 两类节点本地上传和素材库显式添加均生成独立 reference_slot_id；同文件再次添加不会合并。短剧渲染素材卡片保留槽位、字段与角色，删除精确对应一份用途，避免旧卡片按 URL 无法确定要删除的项。
5. 短剧明确选择主体素材后释放自动推断的首帧角色；模式协调保留完整字段和槽位，使用共享原生声明，不再把主体图片汇总成普通两帧并改回首尾帧。
6. 短剧结构设置放进可滚动的“素材与模型设置”菜单，避免长分组直接挤入底部工具栏。嵌套选择器使用已有内嵌模式，外部点击判断只保留本节点控件拥有的下拉列表，选项点击不再提前卸载表单。
7. 短剧报价计算将本地素材校验异常转为稳定错误状态；显示原因并停止安排 HTTP 报价，修复后重新报价。修复前真实控制台出现 watcher／scheduler 异常；最终新页面复核没有异常，也不再一直显示“计算中”。

新增信息继续放在既有可选节点 JSON 中，不改变 API、权限、状态枚举或供应商参数合同。旧数据无槽位时仍保留谨慎的 URL 回退，歧义时不猜测批量替换对象。

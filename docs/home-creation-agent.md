# 首页通用创作 Agent 实施记录

首页及 `aigc_llm` 使用 Neuron AI 4.1.9 组织自然对话和工具调用。用户预选模型；收费创作默认先给方案和估价，确认后执行。自动模式在用户设置的工具预算内执行。现有模型市场和业务应用负责实际结算，Agent 只记录关联。

## 范围与交付

- 后端分支：`feature/agent-enhancements`，前端使用同名分支。
- 保留旧聊天接口；新增接口位于 `app.aigc_llm.agent/*`。
- 首发：问答、方案/剧本、图片/视频工具接入、DOCX 文档、素材、模型偏好、会话作品。
- 无限画布、短剧画布不在改动范围。
- 复用开放工具已发布契约。仅审核过的提交/估价/任务查询操作可被 Agent 使用，管理和删除操作不自动开放。

## 执行契约

提交带客户端 request_id；服务端按租户、用户幂等。每次运行冻结模型偏好、素材和请求。普通文本模型消费仍按既有规则结算。工具计划存参数、契约版本、报价和确认版本。确认后执行同一参数；报价变化时重新确认。

运行状态：queued、running、awaiting_confirmation、waiting_tasks、success、partial_success、failed、canceled、needs_review。工具提交前持久化 submitting；崩溃或提交结果不明时 needs_review，不能自动重发收费请求。已知业务任务只查询恢复。停止阻止新步骤；已在执行的上游请求按实际支持程度收尾并结算。

模型调用保留 tool_calls 和 tool 结果消息。原始会话记录与模型上下文分离；持久化数据库事件支持浏览器刷新恢复。工作进程不持有数据库事务执行网络请求。租户、用户、价格与凭据不能由模型指定。

## 工具目录与身份

OpenCatalog / OpenContracts 提供已发布参数、响应及版本；OpenToolRegistry 限定可执行入口。OpenToolAdapter 接入原业务服务。首页使用当前登录身份，执行应用和用户权限校验，不伪造 API Key，不经过开放 API 密钥额度准入。开放平台原调用保持原有鉴权。

不完整的任意对象 Schema 不发布为 Agent 可执行能力。模型先搜索工具，再取完整参数说明。模型偏好不能被工具参数覆盖。输出关联原业务 task/result，避免重复存储与重复扣费。

测试覆盖模型工具往返、旧聊天兼容、错误和断流、确认重复/过期、任务归属、未知提交不重试、模型偏好不回退、作品归属及 DOCX 可读性。真实付费生成单独记录，不能用模拟测试代替已验证声明。

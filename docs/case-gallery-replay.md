# 案例广场创作配置

案例复刻使用现有 `app_case.config_json`，不新增数据表或迁移。

- `schema_version: 1` 和 `generation_request` 保存可编辑的创作输入；原有展示字段保留兼容。
- 任务设为案例时保留准确的模型身份、数量、画面规格、请求时长、模式、声明参数及参考素材的顺序、角色和用途。
- 数字人保存形象、音色及原始驱动方式；文案任务的合成 TTS 不作为原始驱动音频。
- 后台保存未提供的字段沿用原值；显式传入空配置表示清除配置。
- 无快照的旧案例按同租户、同应用的成功来源任务批量补齐响应，不修改历史任务或数据库。视频时长复用历史请求时长解析，避免取成品实测时长。
- 无来源任务的旧案例保留已有配置；无法恢复的字段由管理员补充。
- 返回 `generation_request` 和 `reference_image_urls`，素材保留持久 URI，展示地址按存储信息解析。费用、凭据、幂等键和供应商回执不进入案例快照。
- 现有租户案例应用选项接口支持 `include_generation=1`，附带公共模型能力配置。无需授予应用配置管理权限。

前台按准确模型标识恢复创作输入，并重新使用当前模型声明和报价规则验证。复刻只填入创作台，不自动提交生成。“用作参考图”仍使用案例成品图或视频封面。

验证：`tests/Feature/CaseGenerationTest.php`；前端 `pc/tests/case-generation.test.cjs`、历史恢复与共享生成参数回归测试。

# 图片与视频提示词增强配置

租户后台在图片生成、视频生成各自的应用配置中选择增强模型，并编辑增强指令；两者相互独立。默认“自动选择”沿用现有文本模型选择规则，空指令沿用各应用的系统默认指令。恢复默认后保存生效。

配置保存在原有租户应用 config_json 中：prompt_enhance_model_id 使用算力市场产品 ID，prompt_enhance_system_prompt 为最多 12000 字的指令。无需数据库迁移；旧配置缺少字段时保持原行为。指定模型必须对本租户可用，执行时禁止跨模型自动回退；自动选择仍保留原有回退规则。增强请求中的客户端模型或指令字段不能覆盖租户配置。

配置接口附加 prompt_enhance_model 元数据供前端显示；租户管理接口附加可用模型选项和系统默认指令。用户配置接口不返回自定义系统指令。增强成功保留原 prompt/charge_points，并增加实际 model_code/model_name。继续使用现有对话鉴权、敏感词检查和计费链路，长度及素材引用结果校验保持不变。

验证使用事务回滚的本地配置测试及模拟增强响应；不发起付费生成。工作室、Agent 对话模型选择、图像/视频生成模型选择不受此配置影响。

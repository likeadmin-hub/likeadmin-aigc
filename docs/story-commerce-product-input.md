# 剧情带货商品原文保护

用户填写的商品名称与已确认卖点始终保存在 `product_info`，按提交原文保留标点、换行和前后空白，仍限制为 3,000 字。AI 仅返回独立的 `product_observations` 和剧情脚本。图像理解请求同时携带用户原文、商品图片和剧情配置；生成视频时使用用户确认信息和独立的图片识别补充，并明确用户确认信息优先。

PC 与移动端在原文下方独立展示“AI 识别补充”；后台记录和模板编辑也区分两种来源。没有识别补充时允许空字符串，原文为空时保持为空。无需新增数据库列、迁移、接口路径、菜单权限或改动其他工具，两个字段继续保存在本工具已有 JSON 草稿、任务快照和模板中。

新分析结果不接受 AI 返回的 `product_info` 作为原文。已经受理的旧响应及旧结果中，该字段仅作为识别补充读取；回填和从分析结果新建草稿均保留请求快照的用户原文。不批量改写历史数据，也不把旧 AI 整理文字伪装为已恢复的用户原始输入。

没有补充字段的旧草稿沿用原脚本校验键；有补充信息时，该字段参与脚本有效性检查。保留原有租户/用户归属、版本和分析期间编辑保护；回填请求期间发生手动修改时保留当前内容，并同步已推进的草稿版本，后续保存不会因旧版本被拒绝。

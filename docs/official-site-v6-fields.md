# 官网配置字段清理（版本 6）

## 范围与来源

以当前 PC 官网的 `OfficialSiteContent`、导航、页脚，以及 `/official/open`、`/official/enterprise`、`/official/help`、`/pricing`、`/join-opc` 页面实际读取字段为准。

`OfficialSiteFields::schema()` 是有效字段清单。租户管理接口返回 `field_schema`，后台据此渲染表单；公共接口不暴露此编辑元数据。新增配置字段须同时增加真实消费者和字段清单。

## 清理内容

- 基础配置移除旧工作台按钮、演示按钮、视频按钮、粒子开关、旧导航分类文字和关闭菜单文字；保留当前导航按钮、SEO、品牌、主题、页脚、模型空态及价格页合作按钮。
- 模块移除未使用的旧背景素材、背景封面、背景类型；小标题仅保留在价格与合作页；动效节奏仅保留在弧形展示、立体场景、创作方式卡片。
- 创作能力图标卡片只配置名称、图标、链接和显隐排序。
- 场景卡片移除图标、补充标签和功能状态；保留媒体、介绍、按钮与链接。
- 模型卡片移除内置图标、补充标签、状态及可编辑路由；类型和路由仍由真实市场模型决定，自定义图标与媒体保留。
- 资讯和说明页卡片移除未渲染的图标、按钮文字、状态；资讯保留补充标签。
- FAQ 只保留问题、回答和显隐排序；页脚链接移除介绍、图标、媒体和按钮文字。
- 卡片旧 `kind`、`canvas_image` 字段移除。首屏卡片保留素材、封面、用于无障碍描述的标题及显隐排序。
- 模型导航移除不会读取的手工分组；仅模型菜单保留面板介绍，其余菜单保留实际使用的分组、概览按钮和导航行为配置。
- 价格、合作模块移除页面没有使用的按钮和媒体字段。价格模块的显示开关不再作为表单项；合作模块开关明确标记为“价格页合作入口”，不表示关闭合作交易页面。

模块标识、显隐、排序和统一列表容器仍保留为内部结构字段。历史模板定义继续用于识别并升级老租户配置，不再成为当前可编辑字段。

## 升级与保留

- 首次读取旧配置时，先按租户备份到 `official_site.config_before_v6`，再持久化版本 6；不需要 SQL 迁移。
- 小于版本 5 的历史模板修复仍执行。版本 5 的用户自定义文案不重新按历史默认值判定。
- 保存和读取使用相同字段清单，已移除字段不会再次进入有效配置。
- 已使用的文案、品牌、模块状态、卡片排序、媒体、独立视频封面及手机素材保留；不会删除素材库文件，也不会复制本机素材到其他租户。
- 本次前后端源码须配套更新，后台表单依赖后端返回的字段清单。

## 验证

- `OfficialSiteConfigTest` 覆盖历史模板升级、旧字段清理、配置幂等、模型路由与导航分组、有效媒体保留。
- 本地租户升级前后保留字段仅版本号变化；后台保存成功并重新读取一致。
- 实际检查后台场景、页脚、价格字段及官网首页、模型区、价格、合作、帮助页面。

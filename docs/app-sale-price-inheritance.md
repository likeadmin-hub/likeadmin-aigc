# 应用生图售价继承

商品图、局部重绘、一键消除、商品套图、商品多角度、服饰套图、换发型、试衣、老照片修复、模特穿戴、图片风格化、去背景、图片翻译、无缝扩图的应用售价支持继承。

- 空值/null：按当前所选算力市场模型及规格的用户售价计费。
- 数字（含 0）：应用独立售价，0 明确表示用户免费；租户仍按算力市场成本扣费。
- 租户后台勾选“跟随算力市场”保存 null，取消勾选后可输入独立售价。
- 既有数字原样保留，包括历史默认值和 0，无法可靠区分过去人工设置与自动填入的数据，不批量重置。需要继承的旧配置可在后台切换。
- 新配置和自动新增价格套餐默认继承；批量应用按数量计算。报价和任务保存实际有效金额，后续改价不重算历史订单。

升级执行 `upgrade/20261012_app_sale_price_inherit.sql`，或安装相应应用迁移。五个独立售价列允许 NULL；迁移不修改已有值。JSON 配置不需表结构迁移。

AIGC 生图自身继续统一由算力市场定价，不恢复已移除的通道调价。其他非生图应用的原有定价方式不在本次变更范围。

# 1.0.391 更新说明

1. 升级前必须将本项目网站切换至 PHP 8.2，并排空、停止对应任务进程和计划任务。更新后网站、任务守护进程和计划任务必须统一使用 PHP 8.2；共享服务器仅调整本项目，避免影响其他网站。
2. 升级短剧创作能力，完善多集规划、画布分页面与制作流程。
3. 短剧智能创作改为 PHP 原生运行，不再需要 Python 创作服务；优化素材复用和生成结果恢复，保留现有业务、计费与任务流程。
4. 在线更新自动升级配套依赖，完善更新失败后的恢复能力。
5. 修复渠道总览菜单入口，打开新版渠道管理页面。
6. 修复后台菜单刷新后出现错误页面，以及菜单链接多余问号的问题。
7. 补齐新安装所需任务结构，修复部分安装环境守护进程无法启动的问题。
8. 修复手机端邀请链接，保留推广信息并直接打开手机端。
9. 手机访问网站自动进入手机端，电脑访问保持 PC 页面。
10. 修复部分后台扩展资源加载失败，并补齐短剧工具介绍的多语言文本。

## 升级步骤

已安装 1.0.390 的站点可以直接升级至 1.0.391，无需先安装中间版本。升级前将本项目网站切换至 PHP 8.2，并等待在途任务完成后停止本项目对应任务守护和计划任务；升级成功后以 PHP 8.2 重新启动这些进程。在线更新会自动部署依赖，无需在客户服务器手动运行 Composer，也不再需要 Python 创作服务。

部署前备份数据库、代码和持久化文件。更新失败会恢复代码、依赖选择和版本标记；已经成功执行的增量数据库变更不会自动反向删除，恢复时遵循更新器提示，避免重复执行。升级完成后确认对应任务进程已切换到新版本并继续运行。

已有站点请按 [后台刷新路由说明](../admin-refresh-routing.md) 与 [平台刷新路由说明](../platform-refresh-routing.md) 核对现有伪静态规则，代码更新不会替换客户保存的 Nginx 配置。

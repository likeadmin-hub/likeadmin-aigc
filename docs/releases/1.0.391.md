# 1.0.391 更新说明

1. 升级短剧创作能力，完善多集规划、画布分页面与制作流程。
2. 优化短剧对话、素材复用及生成结果恢复，保留现有业务、计费和任务流程。
3. 修复渠道总览菜单入口，进入新版渠道管理页面。
4. 补齐新安装所需的任务结构，修复部分安装环境守护进程无法启动的问题。
5. 更新后必须将网站及对应任务进程的 PHP 版本切换到 8.2。共享服务器仅调整本项目，避免影响其他网站。

部署前须备份数据库、项目代码和持久化文件。网站 PHP、任务守护和计划任务应使用同一项目的 PHP 8.2。依赖交付方式和最终发布校验结果在完成后记录。

后台采用 History 路由。已有宝塔站点仍须按 [后台刷新路由说明](../admin-refresh-routing.md) 和 [平台刷新路由说明](../platform-refresh-routing.md) 核对并重载站点规则；代码更新不会自动替换已保存的 Nginx 配置。

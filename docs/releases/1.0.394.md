# 1.0.394 更新说明

1. 新增 AI 智能装修，支持模型选择、多轮调整、图片参考、候选预览与草稿恢复。
2. 统一移动页面装修的字号和尺寸规范，完善组件配置校验与旧页面兼容。
3. 完善视频效果预览，增加广告场景模板的导入能力，简化效果编辑。

本次更新适用于已安装 1.0.393 的站点。升级前备份数据库、代码与持久化文件，排空并暂停本项目任务进程和计划任务；使用 PHP 8.2 完成更新后再恢复运行。

智能装修默认关闭，启用后仍需选择有效模型并确认本轮预算；只有主动应用候选才改变草稿。当前推荐模型的真实效果验收尚未完成，不将可选模型视为同等效果。广告场景模板由管理员主动导入，来源素材使用授权由部署方核实。

小程序构建、系统更新发布与微信平台上传、审核、发布分别处理，本版本不自动上传微信。

# 1.0.393 更新说明

1. 完善平台与租户的 API 管理，支持快捷授权和批量配置。
2. 丰富自动接口文档、能力分类和计费说明，提升查找与接入体验。
3. 完善常见大模型调用和流式输出，优化调用记录与费用追踪。
4. 新增视频生成能力与更多创作选项，改善历史作品再次创作体验。
5. 图片创作工具支持跟随算力市场定价，完善独立售价设置。
6. 优化数字人创作与任务完成体验，图片数字人成为内置应用。
7. 完善多语言、账号偏好、主题皮肤与模型图标展示。

本次更新适用于已安装 1.0.392 的站点。升级前备份数据库、代码与持久化文件，排空并暂停本项目生成任务、任务进程和计划任务。升级完成后使用 PHP 8.2 恢复这些进程，核对页面、任务与消费记录。

图片数字人按内置应用规则开放，具体生成能力仍遵循本站商城与计费配置。API 调用继续由管理员配置并启用，已有授权与租户独立停用设置保留。

更新失败按更新器提示恢复，保留已经执行的增量数据库变更和更新记录。小程序构建产物与版本同步，实际微信上传、审核及发布由对应租户操作。

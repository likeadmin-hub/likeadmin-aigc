1. 首页新增通用创作助手，支持自然对话、创作方案、图片、视频、文档、音乐、试衣和文字配音。
2. 新增技能配置与技能收藏，支持自定义提示词、展示素材和直接启停。
3. 支持上传文档及音视频理解，并按需确认语音转写。
4. 完善分阶段回复、话题隔离、连续创作、断线重连和刷新恢复，直接生成无需填写预算。
5. 新增跨会话作品库，支持预览、下载、收藏和继续创作，删除与恢复同步到关联素材。
6. 新增首页音乐创作，优化数字人素材选择、声音克隆价格展示和会员购买确认。
7. 修复全新安装后租户 API 管理菜单缺失及算力市场状态读取报错。

本次更新适用于已安装 1.0.398 的站点。请按更新预检提示排空任务并暂停本项目的进程守护和计划任务，更新完成后恢复原统一任务启动入口。音乐与配音需配置可用服务。版本开放由平台运营人员手动操作。

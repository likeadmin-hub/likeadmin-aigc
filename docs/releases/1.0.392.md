# 1.0.392 更新说明

1. 新增开发者控制台，支持密钥、调用记录、异步任务和用量账单管理。
2. 支持已开放商城接口和工具能力接入，完善接口文档与在线调试。
3. 升级创作首页和图像、视频创作体验，支持多张图片创建和视频效果选择。
4. 新增素材收藏、标签分类、分页加载与回收管理。
5. 优化对话工作区、模型选择和历史会话体验。
6. 完善主题皮肤与个人中心交互，优化详情弹窗、筛选和调用统计。
7. 改善短剧智能规划与素材处理，提升图片上传兼容性。

本次更新适用于已安装 1.0.391 的站点。升级前备份数据库、代码与持久化文件，暂停并排空本站生成任务，再停止本站对应任务进程和计划任务。升级完成后以 PHP 8.2 恢复这些进程，并核对页面、任务及消费记录。只调整本项目，不改动其他站点。

开放调用沿用本站用户的会员资格与积分。已有租户默认保持关闭，管理员配置并启用相应能力后方可调用；具体可用范围以能力目录为准。

更新失败时按更新器提示恢复。已经成功执行的增量数据库变更不自动删除，请保留更新记录，避免重复操作。小程序构建产物随版本同步，实际微信上传、审核及发布由对应租户操作。

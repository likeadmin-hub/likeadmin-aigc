# 短剧输入可靠性调整（2026-09-26）

## 功能变更

1. 短剧创作与画布技能分离，普通创作、上传后的策划及新修改不混入技能要求；画布保留手动技能选择。
2. 创作和修改提交支持断线后的同次请求确认，减少重复新建；切换账号或租户时不应用旧页面的提交结果。
3. 新画布工作流保留完整初始需求、当前创作产物和累积修改要求，容量不足明确拒绝，不静默裁剪。
4. 格式修复携带原始返回并要求保留创作内容；局部修改目标不明确时要求澄清，完整台词无法适配限定时长时保留原文并提示调整。

## 工程边界

- `server` 与 `web` 均使用 `feature/short-drama-enhancement`；源码提交集成到本地 develop 后验证，远端只推 feature。
- 新脚本请求 `_input_contract_version=1`；新画布工作流版本 `2026-09-26.1`。旧任务不批量迁移，旧工作流仍按其版本处理上下文。
- 普通脚本 create/message 新增可选 `submission_key`，现有路径、权限和响应核心字段不变。旧客户端未传 key 时保留原行为；上传接口本次没有增加提交幂等键。
- 幂等记录复用现有任务字段，按租户、用户、操作隔离；MySQL 命名锁只保护本地创建阶段，不跨模型请求。相同 key、不同请求内容拒绝复用。
- 共享文本运行器的“只接受最终正文”和“不静默切换模型”仅显式启用，新短剧请求开启，其他应用保留原默认行为。容量估算不是精确 tokenizer。
- 无新增数据库字段、迁移、菜单、权限、存储、计费规则或安装卸载改动。不改 manifest 版本，不发布应用或系统包，不提交编译产物/本机代理配置。

## 验证记录

- 脚本输入、时长、上下文、提示词配置回归：83 项（含 6 项默认跳过的数据库用例），新增边界用例通过；实际模型提交边界捕获验证租户创作规则/用户原文保留、技能内容排除。
- 共享模型协议及画布回复、意图、创作设置专项：69 项、641 assertions 通过。
- 真实 MySQL 事务回滚测试：重复提交/内容冲突、规划单元共 4 项、16 assertions 通过。
- PC 输入及画布消息/流式/首次提交专项：73 项通过；3 个受影响 Vue 页面/组件编译及 API TypeScript 语法检查通过。
- 本地 HTTP/MySQL/浏览器集成通过：入队、SSE、刷新恢复、停止、租户切换、文本安全、附件和版本回写；使用隔离测试记录与模拟回复，没有付费模型调用。
- Agent worker/execution/stop 数据库集成通过：提交授权、无跨模型调用事务、重复 worker 不重发、技能快照保留、停止及迟到结果隔离。
- manifest、API 声明、菜单和权限 JSON 解析通过。没有执行完整生产构建或线上部署。

## 未覆盖及已知限制

- 全量历史测试未全绿：AutoDuration 的默认时长断言及 ScriptPlanGenerationContract 的 4 个旧生成用例，在修改前服务代码上已复现相同失败；另有依赖旧编译哈希文件/生成 HTML 的测试失败。未修改编译产物来满足旧断言。
- 不承诺模型语义质量绝对不变或永不报错。真实上游的长剧本、不同模型、完整多集人工质量验收尚未执行；本次主要验证输入保真和状态/失败边界。
- 超长完整台词暂不做自动语义拆镜，返回可解释冲突；超容量上下文不做有损总结。自动时长允许在单镜上限内扩展以容纳对白，显式时长/时间码不自动拉长。
- 上传接口的完整幂等化、所有历史任务升级不在本批范围；不能将 create/message 的重复提交保护描述为所有提交接口均已覆盖。
- 既有常规聊天历史条数上限仍保留；完整保留措施针对新版工作流的创作需求、当前产物、所选文本和累计修改约束。

## 生效与回退

- 本地先检查各 worker 队列无执行中任务再重载统一 worker 组；保留历史 pending 和失败记录。线上尚未部署，需排空在途请求后更新并重载常驻 worker。
- 完全回退前先排空本版在途任务，前后端一起回退至本批之前的兼容代码；不删除任务、原始输入、版本或收据。不建议在处理中的新任务上直接切换旧代码。
- 仅恢复旧 `generation_version` 配置不能单独关闭本批所有保护，本批还包含独立输入契约与工作流版本。

# Kimi K3 官方容量默认值

2026-10-15，根据用户授权，以官方参数作为缺少渠道元数据时的默认值。

- 精确模型代码 `kimi-k3`：上下文 1,048,576 tokens；默认输出额度 131,072；官方输出参数上限 1,048,576。
- 输入与输出共用上下文，默认 Agent 输入预算 917,504 tokens，包含系统提示、历史、工具和资料；本地仍采用估算而非供应商精确分词。
- 正值渠道/管理员容量优先；应用显式输出和后台默认输出优先；输出受渠道输出上限及总上下文约束。独立输入上限未公布，不虚构一个固定输入上限。
- K3 不再受本地通用 32K 输出上限限制；其他模型保留原有默认和上限。不扩展视觉、权限、协议、推理强度或重试行为。
- 保留渠道已有协议的输出字段映射，官方已弃用但保留的 `max_tokens` 仍用于现有 Chat 渠道；容量别名不再通过附加参数重复覆盖已解析的输出额度。
- 无数据库迁移、价格或余额改写。输出额度不是预扣金额，仍按上游真实 usage 结算；实际生成更长时用量可能增加。
- 官方默认不代表转发渠道容量经过实测。LikeAdmin 页面只标注“按渠道默认”；若后续提供明确限制，显式元数据会优先生效。没有通过付费请求探测上限。

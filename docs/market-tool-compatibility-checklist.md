# 算力市场与创作工具兼容检查

本清单用于开发排查，不修改模型上架、租户设置或用户任务。图片和视频模型的实际输入取决于模型合同、所选素材模式和 SKU；目录可见不代表所有参数组合已通过实际生成验证。

2026-10-29 本地租户 1 的旧模型和应用 API 基础复核结果、测试范围及待核验事项见 [专项复核记录](market-legacy-model-adapter-review-20261029.md)。

## 只读目录检查

在目标环境的服务端目录运行（必须明确租户 ID）：

```sh
php tools/audit-tool-market-compatibility.php --tenant-id=1 > /tmp/market-compatibility.json
```

脚本读取该租户当前可售图片、视频目录和本地合同，不请求上游、不提交任务、不扣积分。输出每个模型的入口可见性、参数字段、素材模式及各字段的类型/角色/数量、比例/时长/分辨率选项和 SKU ID。目录可能随租户上架配置变化；SKU 的锁定参数可能进一步收紧这些选项。应用 API 不使用模型原生合同指纹检查，标为 `unverified_app_adapter`。

`native_contract` 为 `matched` 表示本地同步的参数和素材声明与本地原生合同指纹一致；`missing_local_contract`、`missing_model_code`、`changed_or_invalid` 和 `unknown` 需要人工复核。它们均不代表在线上游一定失败，亦不触发禁用。合同文件不可读时为 `unknown`。画布入口目录自身会捕获读取异常，因此 `not_listed_or_unknown` 也可能表示目录读取异常。`scenario_compatibility` 始终为 `unverified`：指纹匹配不等于每种业务场景或 SKU 已验证。

该工具仅输出字段名称、声明及目录选项，不输出请求提示词、素材地址、账号密钥或价格。它使用运行服务的内部元数据解析方法，以保持与模型实际处理方式一致；内部方法变化时需要同步维护此工具。

## 各入口检查范围

| 入口 | 目录和场景 | 参数及素材检查重点 |
| --- | --- | --- |
| 短剧 | 图片默认模型组使用图片模型；视频模型组包含视频模型和视频应用 API。部分图片应用 API 可由特定入口选择，需单独验证。 | 主体、场景、分镜图片和分镜视频分别检查；画幅、分辨率、时长及首尾帧/参考素材受场景约束，部分上游参数由短剧业务白名单处理。 |
| 画布 | 图片模型及 Nano Banana 应用 API；视频模型及视频应用 API。 | 图片参考图数量、视频素材角色和素材模式；对比估价与实际提交、SKU 限制和高级参数。画布提示词可能在展示估价后补充，需检查其对合同和计价的影响。 |
| 独立生图 | 图片目录中的模型及已接入应用 API。 | 提示词、参考图、比例、分辨率、数量、高级参数，以及应用 API 的特定适配。 |
| 独立视频 | 视频目录中的模型及已接入应用 API。 | 生成方式、图片/视频/音频素材角色、首尾帧、时长、比例、分辨率和高级参数；特效指令可能在初次估价后加入，需复核。 |

列表中的模式是市场声明，具体入口和场景不一定提供全部模式。未知字段不应视为支持；保留各入口的权限、合同和素材校验。

## 共享请求准备（第一阶段）

公共参数定义及高级参数处理由 `power/MarketGenerationControls` 提供；原画布参数类保留兼容转发。PC 公共参数、素材编辑组件位于 `components/ai-generation`，既有画布路径保留转发，保存的画布元数据格式保持兼容。本阶段未改变后台 `capability_profile` 的定义、来源或展示。

图片模型通过 `MarketImageModelRuntimeService::prepareRequest` 产生内部不可变的 `PreparedMarketGeneration`。估价、预占和提交使用同一准备入口，计费素材数量从准备后的原生输入取得；按次旧 SKU 保留原计费语义。旧图片适配器对同步声明中的字段执行类型、枚举和边界校验，将大小写等表示转换为声明值。只有明确缺少未来提示词的初步估价可延迟该字段，不能用于真实提交。预占后的准备失败在发出供应商请求之前进入既有幂等失败退款流程。

仅以示例描述的旧结构化对象仍由现有适配器构造，不能把示例当成完整合同或补造嵌套限制。视频和应用 API 的专用请求适配器、按文本摘要解析的历史计价规则以及短剧中的模型专用处理仍待后续阶段迁移。新增模型复用测试验证的是共享机制与已列出的声明约束，不代表实时供应商支持或全 SKU 实测。

本阶段在本地 `develop` 验证：132 项 PHPUnit 用例通过，包含图片准备、旧目录样本、图/视频请求、素材、参数、能力校正、重复提交及准备失败的本地回滚用例；PC 相关 203 项测试及公共/兼容组件的 Vue、Sass 编译通过，独立 PC 编译通过。画布定价产物用例使用 `TEST_PC_MANIFEST` / `TEST_PC_PUBLIC_DIR` 指向独立编译产物通过，没有覆盖站点已存在的 `server/public` 输出。

另有一项既有测试问题：`UnifiedCreateImageQuantityPricingContractTest` 仍要求 `Number(selectedUnitPrice.value) * selectedQuantity.value`，但本次修改前的前端提交 `cfc075715` 就已不包含此表达式，当前页面展示服务端报价的 `user_charge_points`。该旧断言仍失败，本阶段未为通过它而修改定价行为或删除断言。未执行新增收费生成、模型上下架、后台能力校正或历史任务修复。

## 模型或工具变更时逐项复核

1. 检查租户可售 SKU、模型原生合同状态和所选模式；合同缺失或变化时对照同步声明及真实适配器，不据此自动推断失败。
2. 检查必填项、类型、枚举、素材字段及角色、数量上下限、SKU 锁定值和业务入口限制。分别检查无素材、合法素材、缺必填和超限情形。
3. 对照同一用户选择的估价、预留和提交请求，确认模式、素材及会影响计费的参数一致；测试拒绝路径不绕过校验。
4. 为涉及的入口执行离线合同测试和针对性回归；必要时在授权的测试环境进行真实模型验证。报告中单独注明未实测的组合，不把目录扫描视为全量适配测试。

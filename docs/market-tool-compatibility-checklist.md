# 算力市场与创作工具兼容检查

本清单用于开发排查，不修改模型上架、租户设置或用户任务。图片和视频模型的实际输入取决于模型合同、所选素材模式和 SKU；目录可见不代表所有参数组合已通过实际生成验证。

2026-10-29 本地租户 1 的旧模型和应用 API 基础复核结果、测试范围及待核验事项见 [专项复核记录](market-legacy-model-adapter-review-20261029.md)。

## 只读目录检查

在目标环境的服务端目录运行（必须明确租户 ID）：

```sh
php tools/audit-tool-market-compatibility.php --tenant-id=1 > /tmp/market-compatibility.json
# 可选：只构造合成请求，逐个可见 SKU 检查一个代表性模式输入。
php tools/audit-tool-market-compatibility.php --tenant-id=1 --probe-requests > /tmp/market-request-probes.json
```

脚本读取该租户当前可售图片、视频目录和本地合同，不请求上游、不提交任务、不扣积分。输出每个模型的入口可见性、参数字段、素材模式及各字段的类型/角色/数量、比例/时长/分辨率选项和 SKU ID。目录可能随租户上架配置变化；SKU 的锁定参数可能进一步收紧这些选项。应用 API 不使用模型原生合同指纹检查，标为 `unverified_app_adapter`。

`native_contract` 为 `matched` 表示本地同步的参数和素材声明与本地原生合同指纹一致；`missing_local_contract`、`missing_model_code`、`changed_or_invalid` 和 `unknown` 需要人工复核。它们均不代表在线上游一定失败，亦不触发禁用。合同文件不可读时为 `unknown`。画布入口目录自身会捕获读取异常，因此 `not_listed_or_unknown` 也可能表示目录读取异常。`scenario_compatibility` 始终为 `unverified`：指纹匹配不等于每种业务场景或 SKU 已验证。

该工具仅输出字段名称、声明及目录选项，不输出请求提示词、素材地址、账号密钥或价格。它使用运行服务的内部元数据解析方法，以保持与模型实际处理方式一致；内部方法变化时需要同步维护此工具。

第三阶段增加以下只读输出，目录读取置于只读数据库事务中，结束时回滚：

- `scenario_matrix` 按文生图、参考图、文生视频、首帧、首尾帧、参考素材和编辑场景列出声明。`declared_support` 的 `true` / `false` / `null` 分别表示存在对应模式声明、存在明确否定、缺少依据；SKU 和真实生成状态始终独立保留待核验。运行目录默认的 false 或缺少模式不能自动当成上游否定。
- `declaration_review` 对保存的 2026-10-18 样本比较完整参数声明（忽略示例），可发现字段名相同而嵌套类型、必填、条件、枚举或边界变化；另外列出只有类型或示例、缺少完整子结构的对象/数组。样本相同仍不证明当前上游合同完整或未变更。
- `sku_matrix` 列出锁定/可选参数名称和计价识别结果，不输出值或价格。`recognized` 只表示本地识别公式；实际场景计价仍待核验。按像素、缺提交前 Token 费用上限（`requires_submission_token_budget`）与未迁移的应用结构化计价会明确标记阻塞。
- `--probe-requests` 对每个可见 SKU 的每个声明模式（无声明时使用有限的旧场景）准备一个合成输入，使用 `.invalid` 素材地址，仅调用无副作用的请求准备方法，不报价、不探测素材、不上传或提交任务。`constructed` 仅表示该输入通过本地构造且提示词与素材地址未丢失；不证明所有角色、边界、参数组合、报价或上游支持。`rejected` 保留错误类而不输出异常原文；`material_not_forwarded` / `prompt_not_forwarded` 提醒检查静默丢失；主体等复杂结构标为 `needs_structured_fixture`。拒绝可能来自代表性输入不适用，须复核，不能据此自动下架。

## 各入口检查范围

| 入口 | 目录和场景 | 参数及素材检查重点 |
| --- | --- | --- |
| 短剧 | 图片默认模型组使用图片模型；视频模型组包含视频模型和视频应用 API。部分图片应用 API 可由特定入口选择，需单独验证。 | 主体、场景、分镜图片和分镜视频分别检查；画幅、分辨率、时长及首尾帧/参考素材受场景约束，部分上游参数由短剧业务白名单处理。 |
| 画布 | 图片模型及 Nano Banana 应用 API；视频模型及视频应用 API。 | 图片参考图数量、视频素材角色和素材模式；对比估价与实际提交、SKU 限制和高级参数。画布提示词可能在展示估价后补充，需检查其对合同和计价的影响。 |
| 独立生图 | 图片目录中的模型及已接入应用 API。 | 提示词、参考图、比例、分辨率、数量、高级参数，以及应用 API 的特定适配。 |
| 独立视频 | 视频目录中的模型及已接入应用 API。 | 生成方式、图片/视频/音频素材角色、首尾帧、时长、比例、分辨率和高级参数；特效指令可能在初次估价后加入，需复核。 |

列表中的模式是市场声明，具体入口和场景不一定提供全部模式。未知字段不应视为支持；保留各入口的权限、合同和素材校验。

## 共享请求准备（第一阶段）

公共参数定义及高级参数处理由 `power/MarketGenerationControls` 提供；原画布参数类保留兼容转发。PC 公共参数、素材编辑组件位于 `components/ai-generation`，既有画布路径保留转发，保存的画布元数据格式保持兼容。本阶段未改变后台 `capability_profile` 的定义、来源或展示。

图片模型通过 `MarketImageModelRuntimeService::prepareRequest` 产生内部不可变的 `PreparedMarketGeneration`。估价、预占和提交使用同一准备入口，计费素材数量从准备后的原生输入取得；按次旧 SKU 保留原计费语义。旧图片适配器对同步声明中的字段执行类型、枚举和边界校验，将大小写等表示转换为声明值。只有明确缺少未来提示词的初步估价可延迟该字段，不能用于真实提交。预占后的准备失败在发出供应商请求之前进入既有幂等失败退款流程。

仅以示例描述的旧结构化对象仍由现有适配器构造，不能把示例当成完整合同或补造嵌套限制。第一阶段保留了视频和应用 API 的专用请求适配器、按文本摘要解析的历史计价规则以及短剧中的模型专用处理；第二阶段的迁移范围见下文。新增模型复用测试验证的是共享机制与已列出的声明约束，不代表实时供应商支持或全 SKU 实测。

本阶段在本地 `develop` 验证：132 项 PHPUnit 用例通过，包含图片准备、旧目录样本、图/视频请求、素材、参数、能力校正、重复提交及准备失败的本地回滚用例；PC 相关 203 项测试及公共/兼容组件的 Vue、Sass 编译通过，独立 PC 编译通过。画布定价产物用例使用 `TEST_PC_MANIFEST` / `TEST_PC_PUBLIC_DIR` 指向独立编译产物通过，没有覆盖站点已存在的 `server/public` 输出。

第一阶段发现 `UnifiedCreateImageQuantityPricingContractTest` 仍要求旧的前端乘价表达式，而改动前的前端提交 `cfc075715` 就已展示服务端报价。第二阶段已将该用例恢复为编译路由检查，并由 `web/pc/tests/generation-quote-behavior.test.mjs` 对页面实际计算属性和报价 composable 验证数量变化、非线性服务端总价、旧响应覆盖保护和按用量价格展示。定价行为本身未修改。

## 共享适配器与视频准备（第二阶段）

`MarketGenerationAdapterRegistry` 集中管理模型资源和已接入应用 API 的运行服务选择。独立视频、画布和短剧使用同一注册入口；模型与应用的身份、图片与视频的类型不能互相冒用。模型运行服务继续拥有模型参数与结果处理，应用运行服务继续拥有各自协议，不能把注册或目录可见视为端到端兼容证明。

图片和视频模型的提交/查询计划由注册表提供。Seedance、Wan、Grok、Happy Horse、全能视频的应用协议保留原调用方法；Happy Horse 与全能视频查询使用 POST。未知视频应用不会落入 Wan 的默认请求构造。应用 API 共用入口显式转换视频运行服务的报价/预占调用参数，并拒绝把图片批量数量用于一次视频请求。新增同格式模型仍复用已有运行服务及声明；新增应用协议需要在共享层明确注册和实现，业务工具不应新增型号判断。

视频报价、预占和提交使用同一请求准备流程，计费上下文取自准备后的原生输入；固定价、按秒及复合计价保留各自规则。按次旧 SKU 不改变历史计价语义。准备结果保留内部规范化业务输入，用于 Seedance 在提交阶段将素材 URL 替换为供应商素材 ID；提示词中的素材序号与预占时的计费上下文保持不变。报价阶段不创建供应商素材组或上传素材。声明了输出尺寸的模型不会静默丢弃不支持的分辨率而改用默认值。

短剧中的 Qwen 尺寸选择与尺寸预检已迁入共享图片运行服务，短剧只传递业务尺寸输入。原 `qwenDimensionSummary` 入口保留兼容转发。后台 `capability_profile`、平台校正定义及截图中的能力表未改动；未修改模型/SKU 上下架、历史任务或价格配置。测试中的本地配置、预占、退款与取消全部在事务中回滚。

本阶段在本地 `develop` 验证：211 项离线 PHPUnit、5 项显式开启的本地事务回滚用例及 2 项独立编译产物检查通过，共 218 项；PC 相关 206 项测试通过。目录读取、短剧高级参数、25 份保存合同的字段连接检查、延迟用量回执及复合计价结算/失败/取消脚本通过。目录回归脚本已改用当前价格规则服务设置测试价格，继续验证报价准入读取新价格与下架状态。PC 生产源码在本阶段未变化，编译产物检查复用第一阶段独立输出，没有覆盖或交付现有 public 产物。

本地租户 1 的只读目录审计列出 108 个模型选项、13 个应用 API 选项及 12 个不可用应用记录。该数量仅表示目录结果；并非所有模式、SKU、素材组合或实时供应商均已验证。旧合同的最新可信来源核对、其他协议族的参数声明完善及结构化计价规则仍需后续推进。未发起新增收费生成或真实供应商素材上传。

## 结构化计价接入（第三阶段）

SKU 同步现在保留可选的 `meter_contract`，共享图片模型、视频模型及已注册视频应用可直接读取，不再要求通过中文摘要表达新规则。此字段是本地新增的接入契约，**不表示当前上游已经提供**；未提供时继续解析原 `meter_summary` / 计费单位。没有改写本地价格或历史任务快照。

```json
{
  "meter_contract": {
    "version": 1,
    "basis": "image",
    "rounding": "ceil",
    "reference_images": {"free": 1, "numerator": 2, "denominator": 56}
  }
}
```

支持的 `basis` 为 `call`、`image`、`output`、`input`、`output_plus_video`、`output_plus_max_video`、`megapixel`；`rounding` 为 `ceil` 或 `half_up_6`。可选参考图附加项仅用于 `image` / `output_plus_video`，按超出免费张数的数量乘分数权重计费。价格仍除以 SKU 的 `usage_unit_size`。不接受任意表达式、未知版本、未知字段或非法分母；显式字段即使为空也不能降级到摘要规则。按像素计费仍因缺少可核验像素报价而拒绝，不因增加声明格式而放开。

明确的按次规则优先于秒数单位，明确的输出时长规则按最终准备后的请求取时长（包括应用参数嵌套时长、帧数/帧率），不能拿原业务输入覆盖准备结果。计价基础也须适用于图片/视频资源类型。历史无显式规则的图片 SKU 仍保留原按请求张数计费行为。快照内的计价公式和素材上下文用于最终结算；规则更新不重新计算旧任务。Nano Banana 及通用图片应用目前仍采用各自历史结算，新结构化规则在报价/预占时明确拒绝，避免未接入共享结算却忽略新规则。

本阶段未改变 `capability_profile` 的定义、能力校正或来源，后台能力表保持原样。旧模型缺少最新可信合同的部分继续待核验，不凭旧样本生成原生合同。

目录请求审计复现了旧视频适配器在不支持的视频/音频组合中忽略素材的情况。共享图片/视频准备层现按素材槽位检查最终原生输入，拒绝未传递的素材，而不是继续以默认文本请求报价或提交；重复 URL 也按槽位检查，提示词里的 URL 不能冒充素材字段。该检查不推断模型支持哪些新素材，也不替代素材角色、数量、合同及 SKU 校验。Seedance 的提交后资产 ID 替换继续沿用准备后的映射与计费快照。

本阶段在本地 `develop` 验证：258 项离线 PHPUnit（1,509 项断言）及 7 项显式开启的本地事务回滚测试（88 项断言）通过，共 265 项；PC 相关 206 项测试通过。旧计价与 API 结算检查、目录新价格/下架准入、25 份合同的创作页/画布字段连接、短剧和画布高级参数检查通过；18 项结算回滚检查覆盖新旧复合计价的成功、失败、取消、重复回执和余额/记录回滚。受影响 PHP 语法及 diff 格式检查通过。前端业务源码和能力表未改动，未重新构建或覆盖本地产物。

全目录审计为 121 个选项、567 个可见 SKU，1,664 个合成请求案例，详细结果和当前上游公开参数声明的只读核对见专项复核记录。没有修改模型上架、SKU、价格或历史任务，没有发起新增收费生成。服务端远端 `develop` 的新编译产物会覆盖受保护的本地输出，按工作区所有者确认暂缓该次远端合并，继续在现有 feature 提交并合入本地 `develop` 验证；本地产物保留。

## 模型或工具变更时逐项复核

1. 检查租户可售 SKU、模型原生合同状态和所选模式；合同缺失或变化时对照同步声明及真实适配器，不据此自动推断失败。
2. 检查必填项、类型、枚举、素材字段及角色、数量上下限、SKU 锁定值和业务入口限制。分别检查无素材、合法素材、缺必填和超限情形。
3. 对照同一用户选择的估价、预留和提交请求，确认模式、素材及会影响计费的参数一致；测试拒绝路径不绕过校验。
4. 为涉及的入口执行离线合同测试和针对性回归；必要时在授权的测试环境进行真实模型验证。报告中单独注明未实测的组合，不把目录扫描视为全量适配测试。

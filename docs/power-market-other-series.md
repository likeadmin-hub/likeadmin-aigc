# 平台算力市场：其他系列

## 范围与数据约定

- 任务分支：`feature/power-market-other`，server/web 同名。
- 平台算力市场页签顺序：模型 API、应用 API、其他系列、模型系列。
- 模型同步新增上游 `other` 类型，仍使用既有商品、SKU、价格规则和历史快照，不新增表、权限、菜单或应用入口。
- `POST /platformapi/power.market/sync` 可选 `catalog_type=other`，只同步其他模型及价格，不同步普通模型和应用 API；未传参数沿用全量同步并包含 other。
- 列表使用 `catalog_type=other`、可选 `other_category_code`；`extend.other_categories` 返回当前有效其他模型的分类，列表与计数采用同一筛选条件。
- 分类来自上游已发布文档目录的模型绑定和分组路径，保存于商品 JSON 快照。支持后续嵌套分组，不通过显示名称或本地数字 ID 猜测分类；没有发布分类的模型显示“未分类”。
- 本次实时模型目录为 other，而定价接口可能仍回传原来的 image/video 类型。同步使用本次模型目录类型，保留定价原始响应；空目录刷新使用上次已确认类型，文档目录异常时保留原分类。
- 商品及 SKU 按原身份更新，已有售价、销售开关、能力校正和历史引用保留。普通模型及模型系列页签不展示 other，创作端的三类生成目录保持原有筛选范围。
- 上游非 Token 规格中的空 `effective_rate_config` 视为可选空字段；Token 规格继续要求完整输入输出费率。

## 可继续执行

- 通过正常登录，只读查看已存在的模型、渠道、应用、API、价格和路由信息；通过已配置 SDK 读取明确的目录 GET，不复制或暴露凭证。
- 读取固定版本平台源码，提取原始依据与摘要；保留源码与部署版本的区别。
- 在本地 AIGC 的 `server/`、`web/` 任务分支实施适配、源码测试、合成素材和完全隔离的本机故障夹具；依旧按 AGENTS.md 在集成本地 develop 后运行。
- 交付 AIGC 源码、证据和待核对项；API 平台配置、策略、价格、账务和部署保持原状。

## 当前禁止执行

平台代码修改／提交／部署，模型或渠道配置保存，策略草稿保存／发布／启停，市场或价格同步，计量上限或加价规则变更，任务状态检测／供应商查询／生成／重试／取消／素材注册，以及真实账务处置。禁止通过关闭智能路由、改备用线路、补平台字段或执行真实调用使验收通过。

只读打开编辑页和查看节点不等于保存配置。本轮未保存或发布任何平台配置；所有目录采集均为 GET，未执行平台生成、检测、任务查询、资产或账务操作。

## 完成口径

已完成的本地软件切片按实际验证结果记录。依赖平台变更或真实调用的项目标为当前边界不允许执行，不计为完成，也不因“全部完成”推定重新授权。若只读资料不足，先提供精确缺项和依据；不反复向用户索要已有文档、schema、源码位置、密码或密钥。

# 逻辑帧AIGC - 商业级 AI 应用聚合与运营平台

[![逻辑帧AIGC：商业级 AI 应用聚合与运营平台产品宣传片](./.github/media/logicframe-aigc-intro.gif)](./.github/media/logicframe-aigc-intro.mp4)

**连接模型与业务，构建可自主部署、可商业运营、可持续扩展的企业 AI 平台。**

逻辑帧AIGC 是一套面向企业、创业团队与行业服务商的**商业级 AI 应用聚合与运营平台**。平台围绕多模态内容生产、企业 AI 服务和自有品牌运营，统一组织模型接入、工具应用、用户权限、会员计费与持续更新，帮助你把 AI 能力转化为可交付的产品与服务。

从电商商品素材、品牌营销内容，到数字人视频、短剧制作与企业内部 AI 门户，逻辑帧AIGC 提供可组合的应用能力与统一的运营后台。企业可以围绕自身业务配置品牌、应用和模型通道；服务商可以结合多租户、会员套餐与积分计费，开展面向客户的 AI 平台运营、行业服务与定制交付。

目前应用市场已包含 **34 款工具应用**，覆盖文本、图像、视频、数字人与音频等方向。我们将持续扩展应用生态，深化场景方案、智能体与工作流协同，逐步建设连接模型、内容生产、业务交付与商业运营的企业 AI 基础设施。

- **加快业务落地**：复用现有应用、模型接入与平台管理能力，将开发精力集中在业务场景和客户需求上。

- **支撑持续迭代**：通过模块化应用与系统更新机制，逐步扩展服务范围，持续积累业务场景、素材和运营经验。

## 快速部署

### 1. 获取代码

```bash
git clone --branch master --single-branch https://gitee.com/likeadmin/likeadmin-aigc.git
cd likeadmin-aigc
```

也可以使用 [GitHub 镜像](https://github.com/likeadmin-hub/likeadmin-aigc)。开源仓库已经包含管理后台、PC 与 H5 的编译产物，Docker 部署不需要额外获取前端源码或安装 Node.js。

### 2. 准备配置

先安装 Docker Engine 24+ 与 Docker Compose 2.20+，再创建配置文件：

```bash
cp .env.docker.example .env.docker
chmod 600 .env.docker
```

编辑 `.env.docker`，替换所有 `CHANGE_ME` 占位值，填写实际域名、数据库密码、系统密钥与初始管理员信息。配置含义、密钥生成和域名示例见 [Docker 部署指南](./docs/deployment-and-operations.md#docker-compose-部署)。

### 3. 校验并启动

```bash
docker compose --env-file .env.docker config --quiet
docker compose --env-file .env.docker up -d --build
docker compose --env-file .env.docker ps -a
```

默认端口为 `8080`。首次启动会准备数据库和管理员；登录平台后台后，再按业务创建租户、配置应用与模型。

| 入口 | 默认地址 |
| --- | --- |
| 平台后台 | `http://服务器IP:8080/platform/` |
| 租户后台 | `http://服务器IP:8080/admin/` |
| PC 前台 | `http://服务器IP:8080/pc/` |
| H5 | `http://服务器IP:8080/mobile/` |

平台后台使用 `.env.docker` 中配置的管理员账号。已有数据卷不会因为修改配置文件而自动重置管理员密码。

使用宝塔或 Nginx + PHP-FPM 部署时，网站、Worker 与计划任务均需使用 **PHP 8.2**。完整环境要求、源码安装与伪静态配置见下方文档。
